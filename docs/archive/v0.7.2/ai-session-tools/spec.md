# 跨会话查阅实现规格

> 2026-11-09，已实现并归档。导航 MVP 与草稿页修订已由用户确认并提交（173b7a4）；本切片实现两个只读会话工具。当前事实以 [接口契约](../../../state/api-contracts.md) 为准，验证范围见 [QA 清单](../../../test/QA_CHECKLIST.md) 模块十六。

## 工具与边界

- `list_sessions({query?, beforeSessionId?, limit?, includeArchived?})`：标题关键词按字面子串匹配，不查询正文；按会话 ID 倒序分页，默认 10、最多 20 条，排除当前会话。返回标题、稳定链接、ID、更新时间、作用域、归档标志，以及 `hasMore/nextBeforeSessionId`。默认不列归档会话。
- `read_session({session, cursor?, limit?})`：session 接受完整本地链接、32 位引用、正整数 ID 或标题关键词。链接严格解析，不发网络请求；多个标题候选返回 AMBIGUOUS 和候选列表，不能擅自挑一个。明确链接可读取已归档会话。
- 本地单用户会话列表中的 GLOBAL / NOTEBOOK 都可查阅；记忆作用域不是会话 ACL。只访问当前数据库，不能解引用外部 URL 或文件路径。
- 工具与记忆开关、vault 授权/索引可用性解耦。v2 聊天且模型启用 tools 时注册会话工具；记忆工具仍要求 memoryOptions.use。复用双协议、全局预算、取消和工具活动持久化。
- 仅读取当前 context_generation 内已结束且保存的用户/助手正文；legacy 仅在 generation=1 时可读。失败/中断原文保留真实 turnStatus，不能当成已完成结果；排除正在执行、已清理、系统提示、思考、附件内容及原始工具结果。返回排除范围说明，不冒充完整历史。
- 使用目标会话已有解锁材料，缺失/无法解密如实返回状态，不尝试别的会话密码。无新增表、索引、缓存、协议注册或磁盘路径。

## 分段与一致性

- 从最早记录开始，每次最多 20 条消息（默认 10）及 6000 Unicode 码点正文；单条超长消息可跨页续读。每段含 messageId、role、createdAt、turnStatus、offset、是否读完该消息。
- 游标绑定目标引用、history_revision、context_generation、消息上界与下一消息/偏移。页内读取使用同一数据库只读事务，读取后复核版本；跨页历史变化返回 STALE 并提示重新读取。改名不改变历史版本或链接。
- 返回 `hasMore/nextCursor/incomplete`、本页范围与省略项。只读结果总大小仍受既有 64 KiB 工具限制及模型上下文预算约束。
- 非法参数（重复键、尾随 JSON、未知字段、错误类型、越界游标）返回 INVALID_ARGUMENT；不存在/已删除返回 NOT_FOUND；空候选 NO_MATCH；解密不可用 UNAVAILABLE。不以其他会话填补失败。
- 历史内容是引用资料，不能覆盖当前指令，也不能因读取历史中的“记住”等话语而触发长期记忆写入。模型回答时引用来源标题与链接，按需续读；不预先加载所有历史。

## 前端

- 复用现有活动组显示「查找历史会话」「读取会话」与运行、条数、分段、歧义、找不到、不可读状态；不显示原始工具参数或正文。
- 回复中的 `[来源标题](drill-notebook://session/<ref>)` 以可点击引用显示。点击打开只读历史预览，复用历史分页；关闭回到原聊天，不切换当前会话、不丢草稿、不新建记录。标题可换行；窄屏预览不溢出；删除/加载失败可理解并可重试。
- 不改导航菜单、主输入区或记忆设置。原始工具结果只在本轮内存续写；安全活动摘要继续加密保存。

## 验证

覆盖筛选/分页/歧义/稳定链接/跨 notebook/归档/删除/版本变化；长消息逐字拼回、解密失败、已清理/跨代/运行中排除；两协议普通/流式续写、记忆关闭仍可读、工具关闭不可执行、预算与摘要不泄漏。前端验证活动、引用预览、错误与草稿保持，运行构建和相关回归。
