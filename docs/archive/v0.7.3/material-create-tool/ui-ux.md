# 新增学习资料工具 UI/UX

> 已于 2026-11-11 随 v0.7.3 归档，仅作历史参考；版本收尾见 [归档说明](../README.md)。下文保留实施时的验证结论。

> 状态：按用户 2026-11-10 授权实现 `create_material`。沿用已确认的工具活动与资料来源交互，不增加表单、常驻卡片或确认弹窗。对应 [v0.7.3 清单](../features.md)。

- 用户要求保存总结、创建资料或加入错题时，模型先通过现有查找 / 读取工具确认所属位置；同名多个目标时询问用户，不凭名称猜 ID。
- 回复内显示「新增学习资料 · 执行中」。事务保存成功显示「已保存」，可点击「查看资料」进入普通资料页面；不自动切走正在进行的聊天。
- 重复请求显示「已存在，未重复添加」，链接仍指向同一个对象。无效参数、目标不存在、会话失效或保存未确认分别显示对应状态，不能以生成了文字冒充保存成功。
- 新建笔记本、笔记页、知识点、题库、题目均使用普通业务对象；笔记正文保存为现有可编辑 Markdown 块。成功后刷新对应目录，保留当前编辑中的内容。
- 人工加入错题显示真实统计，未作答时为 0 次；不制造一次错误。加入后沿用连续答对两次退出与人工移出的规则；重复加入已在错题本的题不重置学习进度。
- 取消生成之前已提交的保存仍保留成功记录。工具执行结果未知时不显示成功，使用同一操作标识重试核对结果。

```text
▾ 已保存学习资料
  ✓ 新增学习资料    已保存             查看资料

已将总结保存到 [极限与连续](资料链接)，你可以继续编辑。
```

本轮仅新增；修改已有正文、删除资料、工具开关及独立 AI 窗口由后续切片设计。
