> 已于 2026-11-11 随 v0.7.3 归档，仅作历史参考；版本收尾见 [归档说明](../README.md)。下文保留实施时的验证结论。

## 输入与保存

`type` 为 `notebook / note / knowledge / bank / question / wrong`，`operationId` 为本轮逻辑新增操作的稳定标识，重试必须复用。工具独立于记忆开关，仍受当前轮次、取消与全局预算约束。正文和历史引用不构成用户授权；工具说明与系统提示只允许执行当前用户委派的新增。

| 类型 | 必需参数 | 可选参数与落点 |
|---|---|---|
| notebook | title | 普通笔记本，沿用创建初始空白页的现有行为 |
| note | notebookId、title、content | parentPageId 必须在同一笔记本；content 为 Markdown，保存为现有 markdownBlock 并在同事务中建立检索条目 |
| knowledge | title、content | bankId（省略为未归属）、category、tags、headingPath、questionIds；关联题目校验复用现有规则 |
| bank | title | description；普通题库 |
| question | bankId、questionType、stem | answer、options、analysis、difficulty、tags、chapter；答案 / 选项遵循现有题型规则，解答题允许无参考答案 |
| wrong | questionId，或完整新题参数 | 已有题只人工加入，不修改题面；新题先保存到明确题库再加入，两步原子完成 |

严格拒绝未知字段、重复键、错误类型、缺失字段、超长和超界输入。每次新增一个对象，正文最多 12,000 Unicode 字符，参数总计最多 64 KiB；列表至多 30 项，选项至多 26 项。不接收磁盘路径、附件写入或任意 TipTap JSON。

## 事务与重复请求

- schema 14 → 15。新增 `ai_material_creation` 保存请求 / 操作标识、指纹、对象类型及 ID，不存资料正文、标题或任意工具参数。归属会话删除时回执级联清理，资料保留。
- 同一请求与 operationId 只能完成一次；参数相同返回 DUPLICATE，参数改变返回冲突。模型更换 tool call ID 不绕过幂等保护。显式 retryOf 重试链可复用先前回执；不同普通消息允许再次创建同名资料。
- 事务第一条语句预占回执以取得 SQLite 写锁，再校验来源轮次和目标，写入业务对象及结果。笔记的页面 / 索引、知识点关联、新题 / 错题标记及回执同成同败。提交前取消回滚；提交后取消不伪称写入失败。
- 被删除的已创建对象不会因重复请求重新生成；返回 NOT_FOUND。已知失败不留半成品回执；未知数据库错误不暴露异常栈或路径。

## 错题成员规则

`question.wrong_manual_after` 记录人工加入时该题最后一次真实作答的 ID（从未作答为 0），旧题默认为 NULL。成员须未人工移出，并且曾答错或被人工加入；在最近答错与最近人工加入两者较新的基线之后，连续答对未满两次。仍在错题本时再次加入不改变基线。

正常错题页面、读取工具与练习共用成员 SQL，统计仍仅聚合真实 `answer_record`。不创建虚假答题，不复制既有原题。

## 结果与界面

成功返回 `CREATED / DUPLICATE / NO_CHANGE`、一个有界 items 条目（类型、ID、所属位置、实际标题、sourceLink）。活动元数据仅白名单保存工具名、结果状态、内部来源链接，不保存内容。前端成功后失效相关目录缓存，来源链接沿用既有普通页面导航。

验证覆盖真实 SQLite 新增 / 普通读取、索引、关联、题型、统计、并发重复、回滚、取消、会话失效、迁移和模拟模型调用链；前端验证安全来源、状态和缓存刷新。使用隔离夹具，不触碰用户资料或真实供应商。
