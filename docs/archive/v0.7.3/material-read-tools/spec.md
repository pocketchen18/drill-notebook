## 工具契约

| 工具 | 定位与返回 |
|---|---|
| `read_current_page` | 默认读取本轮主消息的本地页面快照；`requestId` 可指向同轮已收到的插话。返回标题、位置、采集时间、草稿标识、选中内容与分段正文 |
| `search_materials` | `type`、`query`、可选 `notebookId` / `bankId`；空关键词浏览目录，关键词查找资料，返回类型、稳定 ID、所属位置与有限摘要 |
| `read_notebook` | 无标识列笔记本；`notebookId` 列页面；`pageId` 读取页面正文，保留公式和嵌入题目 / 文件引用 |
| `read_knowledge` | 可按 `bankId` 列知识点；`pointId` 读取 `current` / `original` / `summary`，缺失版本不冒充已有版本 |
| `read_question_bank` | 无标识列题库；`bankId` 列题目；`questionId` 读取题面、选项、答案、解析、章节 |
| `read_wrong_questions` | 按可选题库和关键词分页列出待巩固题，附真实答题次数、错误次数、错误率；`questionId` 读取仍在错题本中的原题 |

- 清单默认 10 条、最多 20 条，`offset` 分页，返回 `hasMore` / `nextOffset`。搜索不自动选中同名候选，读取使用明确 ID。
- 正文默认 4,000 个 Unicode 字符、最多 8,000；使用 `offset` / `maxChars`，返回版本指纹及范围。续读必须带上次 `version`，内容变化返回 `STALE`，不拼接不同版本。结果仍受既有 64 KiB 工具上限约束。
- 笔记正文查找使用现有 `retrieval_chunk` 文本的参数化 `LIKE` 查询；标题和其它资料也使用参数化关键词查询，不走 BM25 排序、不构建第二套内容库或向量索引。目录与查找只取有界摘要，完整正文只读取明确目标。
- 资料引用统一为 `drill-notebook://material/<type>/<id>`，前端只接受已知类型与正整数 ID，再进入普通资料页面。单题通过 `GET /api/questions/{id}` 确认存在并取得所属题库；已删除返回 404。笔记本跳转清除旧本页面，连续点击不同页面来源也要更新目标；知识点来源定位到当前卡片，其快照所属题库来自该卡片。
- 统一返回 `status`、`items`、`incomplete`，可包含 `hasMore`、位置和分页字段。失败不回传异常栈、磁盘路径或任意底层错误消息。与记忆开关独立，仍受模型工具能力、整轮预算、取消和会话状态校验约束。

## 页面快照与生命周期

- 前端 `pageSnapshot` 包含受限的页面元数据、正文、选中内容、草稿状态和采集时间；不读取其他应用、浏览器存储、请求头或 API 配置字段。
- 可选所属题库为空的知识点仍可读取；前端省略 null / 无效定位字段，保留实际目标 ID。
- 后端只向模型预先提供定位提示，不自动注入快照正文。直接发送、排队、重试共用相同快照；插话按自己的请求标识保存。快照正文不进入明文 request/result 元数据，指纹参与幂等判断；队列沿用已有加密存储。
- 当前页是提交时的快照，不承诺读取时数据库最新内容；数据库目标已删除时明确失败。无业务内容的页面返回页面名称与空内容状态，不能残留上一个页面。
- 旧客户端的 `pageContext` 协议保留兼容；新前端不再发送自动注入用的 `pageContext` / `retrievalOptions`。无工具能力时不会暗中恢复整页注入。
