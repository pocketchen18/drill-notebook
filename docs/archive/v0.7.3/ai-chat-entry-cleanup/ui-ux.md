# AI 对话上下文卡片与入口清理

> 已于 2026-11-11 随 v0.7.3 归档，仅作历史参考；版本收尾见 [归档说明](../README.md)。下文保留实施时的验证结论。

> v0.7.3 当前切片；用户已明确要求先移除上下文卡片与重复按钮。需求归属：[版本清单](../features.md)。状态：已实现，前端回归与构建通过（2026-11-09）。

## 界面变化

- 移除聊天顶部“当前上下文”卡片，包括页面标题、正文预览、“使用”“检索笔记”和检索范围控件。会话导航下方直接衔接现有快捷提问与消息区，释放的高度交给消息区。
- 移除主界面右下角圆形 AI 悬浮按钮。右上角“AI 助手”、用户自定义快捷键与业务页定向操作仍可打开助手。
- 设置页删除“显示 AI 悬浮球”选项；设置与刷题页的入口提示改为右上角。旧悬浮球偏好不再读取。
- 保留每条回复的“本轮上下文”检查器、引用、工具活动、附件、队列与插话；它们不属于顶部卡片。

## 过渡行为与后续接入

本切片完成时只清理界面，曾暂时沿用既有页面上下文与检索偏好。随后[资料读取切片](../material-read-tools/spec.md)已接通六个工具，当前前端不再自动注入页面正文或读取旧检索偏好；改为消息级本地快照、模型按需调用工具。详细契约与本次验证只维护在读取切片和状态文档中。

本界面清理切片本身无后端、接口、数据模型或发布配置变更。

## 验收

- 聊天打开与关闭时均无悬浮按钮；打开后无顶部卡片及其控件，不留下空白占位。
- 右上角、快捷键与业务定向入口继续可用，设置页无失效开关或右下角引导。
- 既有上下文请求、笔记引用、消息审计、流式响应及排队相关前端回归通过；前端类型检查和构建通过。
- 施工材料保留至下一版本开始前再归档。
