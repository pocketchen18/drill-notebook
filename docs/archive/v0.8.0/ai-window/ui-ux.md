## 1. 框架总览

助手是一个普通的系统窗口，使用系统标题栏，标题为「AI 助手」，有独立的任务栏按钮。移动、缩放、最大化、贴靠分屏全部交给系统，软件自己不做停靠或分屏。整个应用只有一个助手窗口，多个会话在窗口内切换。

```text
┌ AI 助手 ─────────────────────────────────────────── ─ □ × ┐
│ 会话栏 264px     │ 对话区                          │ 详情栏 320px │
│ [+ 新建会话]     │ ☰ 会话标题  ● 正在回复        ⋯ │ （按需打开） │
│ [查找会话…]      ├─────────────────────────────────┤ 本轮上下文   │
│ 今天             │ 消息流（阅读宽度最多 760px）    │ 或会话引用   │
│ ● 当前会话       │   用户消息 · 绑定的业务页面     │ 预览         │
│   其他会话  待发1│   助手回复：模型与档位 / 思考   │              │
│ 近 7 天          │   / 工具活动 / 正文 / 来源      │              │
│   …              │                    [回到最新 ↓] │              │
│                  ├─────────────────────────────────┤              │
│ 本地存储 12%     │ 待发送队列（贴在输入框上缘）    │              │
│ 清理 · 设置      │ 输入框                          │              │
│                  │ [+] [页面] … [模型][档位][◔][▶]│              │
└──────────────────┴─────────────────────────────────┴──────────────┘
```

三个区域各管一件事：会话栏找会话，对话区读和写，详情栏看某一轮或某个引用的细节。详情栏默认不出现。

| 窗口宽度 | 会话栏 | 详情栏 |
|---|---|---|
| ≥ 1180px | 固定在左侧，可手动收起 | 固定在右侧，与对话并排 |
| 760–1179px | 固定在左侧，可手动收起 | 覆盖在对话区右侧，可关闭 |
| < 760px（分屏后的窄窗口） | 默认收起，点 ☰ 以浮层滑出，选中会话后自动收起 | 占满窗口，带返回 |

- 默认尺寸 980 × 760，最小 420 × 520。首次打开时出现在主窗口所在显示器的右侧；之后记住位置、尺寸和是否最大化。显示器变化导致窗口不可见时，回到主窗口所在显示器。
- 窗口内只有三处滚动：会话列表、消息流、详情栏。输入框随内容增高到 8 行后才在内部滚动，不出现并排的窄滚动区。
- 明暗主题跟随主窗口，切换时两个窗口同时变化。

## 2. 会话栏

- 顶部是「新建会话」和查找框。新建只进入未保存的新会话页，首条消息发送后才出现在列表里。查找按标题筛选，清空后恢复完整列表；没有命中时显示「没有匹配的会话」。
- 列表按最近活动分为「今天 / 近 7 天 / 更早」三组，组内沿用现有顺序。每行一行标题，右侧是状态：正在回复显示转动的小圆点，有待发消息显示「待发 2」，暂停显示「已暂停」，失败显示警示图标。空闲会话右侧显示时间。
- 行的右键菜单和悬停出现的 `⋯` 沿用已有的一份菜单：重新生成标题、重命名、复制、导出、删除。正在回复的行在菜单顶部多一项「停止回复」。
- 底部是本地存储占用和「清理聊天记录」「设置」两个入口。存储条从输入框上方移到这里，不再占用对话空间。「设置」在主窗口打开对应设置页。
- 收起会话栏后，对话区顶栏的 ☰ 负责展开；收起状态随窗口偏好记住。
- **置顶**（会话级，倾斜图钉）：鼠标悬停或键盘聚焦到某一行时出现图钉，点击置顶；右键菜单里也有「置顶 / 取消置顶」。置顶的会话归入列表最前的「置顶」分组，先置顶的排在上面；该分组里悬停时图钉显示为高亮实心，点击取消置顶，会话回到原来的时间分组。置顶不改变会话的最近活动时间。窗口级的「固定」用垂直图钉、放在顶栏，两者靠位置与角度区分。
- **宽度**：会话栏右缘和详情栏左缘各有一条可拖动的分隔条，悬停时显示强调线。会话栏 200–480px、详情栏 280–900px，并分别不超过窗口宽度的 45% 和 65%；宽度各自记住，双击恢复默认，聚焦后可用左右方向键微调。窄窗口下面板是浮层，不提供分隔条。

## 3. 对话区

### 顶栏

左起两段：窗口级控件（☰ 会话栏、📌 固定）——细分隔线——会话标题、运行状态、`⋯`。标题过长时省略，悬停显示全名并提示「双击改名」。运行状态只在非空闲时出现：「正在回复」「待发 2」「已暂停」。`⋯` 是当前会话的同一份菜单，新会话页禁用。

- **固定**（窗口级，垂直图钉）：点击让助手窗口保持在其他窗口之上，便于一边看回答一边在主窗口记笔记；再点取消。开启时按钮为强调色，状态写入窗口偏好，重开助手仍是固定的。助手窗口不提供这个接口时（浏览器调试）按钮不出现。顶栏不放会话级图钉，避免与会话置顶混淆。
- **标题双击改名**：双击标题就地变成输入框，整段文字默认选中，直接输入即可替换；Enter 或失焦保存，Esc 取消，内容为空或没变都不提交。单击标题仍然是展开会话栏（会话栏已展开时单击不做别的），所以单击会延后一拍执行，好和双击区分。新会话页还没有记录，双击不改名。

### 消息流

- 内容列最宽 760px，窗口更宽时居中；窄窗口左右留 16px。表格、代码和公式超宽时各自横向滚动，正文不横向滚动。
- 用户消息靠右，浅底色。消息下方用一行小字标出提交时绑定的业务页面，例如「笔记 · 导数的定义」，点击在主窗口打开；没有绑定页面时不显示。
- 助手回复不加气泡，占满内容列。顶部一行小字是这一轮实际使用的模型和思考档位，之后依次是思考过程（默认折叠）、工具活动（沿用现有折叠组）、正文、来源。来源是可点击的资料或会话链接。
- 回复下方的操作行：复制、插入笔记、重新生成。三个按钮统一为 26px 的灰色纯图标按钮，图标 14px、间距 4px，共用圆角、悬停底色与键盘焦点样式；各自保留同名悬停提示和读屏标签。重新生成使用圆形箭头，点击后用原提问及附件重新回答，使用当前会话的模型和主窗口当前页面，新回答追加到末尾，原回答保留。准备或生成期间、有待发消息时禁用；输入框里的草稿与附件保持原样。上下文明细通过输入区的上下文占用面板进入。右端显示这一轮的用量（有实测值才显示）。操作行在鼠标悬停或键盘聚焦到该回复时出现，最后一条回复始终显示。
- **选中文本**：在任何消息上拖选文字，选区上方浮出「复制 / 引用」。复制写进剪贴板；引用把选中的文字按 Markdown 引用块（每行前加「> 」）放进输入框末尾并聚焦，接着写自己的问题即可。选区贴近顶部时浮层改放在选区下方；点击别处、滚动、Esc 或选区消失都会收起，点浮层按钮本身不会丢掉选区。
- 流式输出时只有读者停在底部才跟随。上翻后停止跟随，右下角出现「回到最新 ↓」；有新内容时按钮带小圆点。折叠和展开不改变当前阅读位置。
- 插话在回复中以「插话 · 已接收」的小块出现，位置对应模型接收它的时刻，沿用现有表现。

### 新会话页

消息流为空时，居中显示一句「开始一段新对话」和三四个快捷提示（讲解当前内容、出几道练习题、整理成知识点、分析错题）。点击只把提示文字填进输入框，不直接发送。快捷提示只在这里出现，不再常驻聊天上方。

### 输入区

待发送队列继续贴在输入框上缘，行为不变。输入框下方是一行工具条，从左到右：

| 控件 | 说明 |
|---|---|
| `+` 附件 | 图片和文本文件，沿用现有限制；也可以直接粘贴或拖入 |
| 页面标记 | 一个小标签，显示主窗口当前的业务页面，例如「导数的定义」。只表示「当前页面」指的是哪里，不显示正文。主窗口没有可读页面时显示「无当前页面」并置灰 |
| 模型 | 显示当前会话的模型名，点击打开选择面板 |
| 思考档位 | 显示当前档位，点击打开菜单；模型不支持调档时不显示 |
| 上下文占用 | 一个小圆环加百分比，点击打开说明面板 |
| 插话 / 停止 | 只在回复期间出现 |
| 发送 | 回复期间含义变为「加入队列」，沿用现有规则 |

- 占位文字：空闲时「问点什么，Enter 发送」，回复中保持「正在回复，可先输入下一条问题」。
- 窄窗口下工具条换成两行：第一行是附件、页面标记、上下文占用，第二行是模型、档位和发送类按钮。模型名过长时省略，按钮文字不被挤掉。
- 页面标记跟随主窗口实时变化，但消息一旦提交，绑定的页面不再改变。

### 模型选择面板

从工具条向上弹出，宽 360px，窄窗口下与输入框同宽。

- 顶部是查找框，按模型名或供应商名筛选。
- 第一项是「跟随主模型」，括号里写出当前主模型。新会话默认选中它。
- 之后按供应商分组列出已配置的模型，每行显示模型名和能力标签（工具、视觉）。缺少上下文窗口或最大输出的模型置灰，说明为「需先补全容量」。
- 底部「管理 AI 连接」在主窗口打开对应设置页。
- 选择后只影响当前会话的后续消息，面板关闭，工具条上的模型名更新。回复期间也能改选，提示一句「从下一条消息开始使用」。

### 思考档位菜单

列出「模型默认」和该模型声明支持的档位。换到不支持当前档位的模型时自动回到「模型默认」，并提示一次。预算型模型显示「模型默认 / 关闭 / 开启」，不硬凑档位名。

### 上下文占用面板

- 只讲三件事：输入（分成缓存命中与缓存未命中）、输出、占模型窗口的比例。第一行「输入 52.4k / 128k」，下面是占比条，再列「缓存命中 / 缓存未命中 / 输出」三行；供应商没回报的字段写「未回报」，不补造数字，也不写成 0。
- 还没有实测值时用待发送内容的本地估算，标「估算」并说明不含工具定义与工具结果。
- 分项估算（历史对话、资料、记忆、系统提示）、摘要缺口与裁剪原因都不在这里重复，交给「查看本轮上下文」。
- 一轮里多次工具往返的累计用量不在这里相加，面板只说一次请求的长度。
- 占用超过 80% 时圆环变为警示色，面板提示「较早的对话可能被摘要或省略」。
- 底部「查看本轮上下文」打开详情栏。

## 4. 详情栏

承载两种内容，一次只显示一种：

- **本轮上下文**：现有上下文检查器的内容，从抽屉改为栏。
- **会话引用预览**：点击回复里的会话链接时打开，只读，沿用现有分页预览。

顶部是标题和关闭按钮。宽窗口下与对话并排，不遮挡正文；切换会话时自动关闭。

## 5. 窗口行为

| 操作 | 结果 |
|---|---|
| 点主窗口右上角「AI 助手」、按快捷键 | 切换：助手未打开、已收起、最小化或被其他窗口盖住时，打开并切到前台、聚焦输入框；助手已在前台时收起 |
| 业务页的定向入口（如「AI 分析错题」） | 同上，并沿用现有行为把带目标的提问填入输入框 |
| 关闭助手窗口 | 窗口收起，不询问。正在回复和排队的会话继续运行 |
| 再次打开助手窗口 | 回到关闭前的会话、草稿、附件和阅读位置，显示任务的实际进展 |
| 关闭主窗口或退出应用 | 两个窗口一起关闭。有会话正在回复或有待发消息时先确认 |
| 下次启动应用 | 不自动弹出助手窗口。打开后恢复上次的会话；被退出中断的回复和待发消息按既有恢复规则显示 |

- 退出确认的文字：标题「仍有 2 个会话正在回复」，正文「退出后这些回复会中断，已生成的内容会保留；待发送的消息下次打开时保持暂停。」，按钮「取消」「退出应用」。没有运行和待发时不询问。
- 主窗口右上角的入口有三种样子：未打开时是普通按钮；已打开时带选中底色；助手窗口已收起但后台仍在回复时，按钮上显示运行中的会话数。这样关掉窗口后仍然知道有任务在跑。
- 助手不遮暗、不阻断主窗口，也不保持在最前；需要并排时用系统分屏。

### 两个窗口之间

- 点击资料来源、页面标记或消息下的绑定页面：主窗口提到前面并定位到该资料，助手窗口保持原样。点击会话链接：在助手窗口内处理。
- 只有用户点击才会切换窗口或页面。后台工具完成、回复结束都不抢焦点，也不改变主窗口正在编辑的位置。
- AI 新增、修改、删除资料后，主窗口对应目录和页面自动刷新，沿用现有的草稿保护。在主窗口改了模型配置、工具开关或记忆设置，助手窗口同步显示。
- 回复结束时如果助手窗口不在前台，任务栏按钮闪烁一次；不弹系统通知。

## 6. 键盘与无障碍

| 按键 | 作用 |
|---|---|
| 现有发送键、Ctrl+Enter 插话、Shift+Enter 换行 | 不变 |
| Ctrl+N | 新建会话 |
| Ctrl+K | 聚焦会话查找框（会话栏收起时先展开） |
| Ctrl+B | 展开或收起会话栏 |
| 打开 / 关闭 AI 助手的全局快捷键 | 在助手窗口内按下时收起窗口 |
| Esc | 依次关闭浮层、详情栏；都没有时不做任何事，不关闭窗口 |

- Ctrl+N / Ctrl+K / Ctrl+B 是默认值，可在「设置 → 常规 → 快捷键」的「AI 助手窗口」分组改绑，只在助手窗口内生效。
- 三个区域分别是导航、主内容和补充内容地标，Tab 顺序与视觉顺序一致。浮层打开时焦点进入浮层，关闭后回到触发按钮。
- 运行状态、队列变化和「回到最新」用礼貌播报，不打断正在朗读的内容。状态不只靠颜色或动画表达，圆点旁都有文字或可读名称。
- 窗口内可点击目标不小于 32px。缩放到 200% 时窗口按窄窗口布局工作。

## 7. 分片落地

框架一次定下，内容分四片进入：

| 切片 | 这一片出现的界面（验收修订见各节） |
|---|---|
| 1 独立窗口 MVP | 窗口与三栏框架、会话栏（现有功能加标题查找，不含分组）、消息流与输入区的迁移、页面标记、详情栏、三个新快捷键、窗口行为与主窗口入口状态。工具条里暂不出现模型、档位和上下文占用 |
| 2 会话模型与档位 | 模型选择面板、档位菜单、回复顶部的实际模型与档位 |
| 3 上下文反馈 | 上下文占用圆环与面板、操作行的本轮用量 |
| 4 体验完善 | 会话时间分组、用户消息下方的绑定页面、回到最新、操作行的悬停显示、窄窗口与键盘的全部细节 |

第 1 片完成后旧的模态侧栏移除，不保留两套入口。

## 8. 已确认的取舍

2026-11-11 用户确认：

1. 关闭主窗口即退出应用，助手窗口不单独留下。
2. 启动时不自动弹出助手窗口。
3. 输入区保留页面标记。
4. 会话按「今天 / 近 7 天 / 更早」分组，第 4 片实现。
