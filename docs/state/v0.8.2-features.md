# v0.8.2 功能需求清单

> 状态：笔记混合检索接入已实现并通过工程验证（2026-11-14），尚未发布。此前从 v0.8.1 顺延的接入决定见[全局清单](../features.md#笔记混合检索接入资料工具v082已实现)。本次只推进该切片，发行配置与历史发布状态保持原口径。

## 1. 本版目标

将既有笔记 embedding RAG 接入助手按需调用的 `search_materials`，让模型用自然语言查找笔记，取得相关片段与来源，必要时再按明确 ID 读取上下文。保留关键词查找、目录浏览和已有读取工具。

## 2. F01 范围与行为

- `searchMode=hybrid|keyword`，默认 hybrid。非空的 `note/all` 查询、无 bankId 时复用 BM25 + 可选向量 + RRF；notebookId 限定笔记本。字面匹配优先，再补充语义候选。
- keyword 用于精确名称、编号、原文或符号，保留有界目录分页；空查询、其它资料类型 / 题库范围及明确 ID 读取不调用 embedding。
- 结果提供页面 / 笔记本定位、真实标题、来源链接和相关片段；同页分块合并，同次调用中的相同笔记片段去重。片段足够时可直接回答并引用，需要前后文才按 ID 分段读取。
- 默认每页 10 项、最多 20 项，每片段最多 240 Unicode 码点、每页总量最多 4,800；混合候选最多 80 项，达到候选上限明确告知。目录使用 60 KiB 软预算提前分页，nextOffset 按实际数量推进，保持共享 64 KiB 硬上限。
- 未配置向量时使用 BM25；已选空间但不可用、重建、覆盖不足、provider 不匹配、异常或超时则附降级说明并采用 BM25。分块哈希、页面存在与当前归属在返回前重新核对。
- 沿用现有工具开关、模型工具能力、授权、运行预算、停止和协议适配。工具参数及资料正文不进入持久化活动摘要；远程 embedding 仍须当前有效授权。
- 不新增数据库表、索引、模型下载或运行时写盘路径，所有落点继续经现有 APP_ROOT 便携策略。

## 3. 验收结果

后端相关 **16 类 / 202 项：201 通过、0 失败、0 错误、1 项既有跳过**；前端相关 **4 文件 / 38 项全部通过**。已覆盖同义查询的 provider 桩、精确查找、范围、分页 / 去重、Unicode 片段与字节预算、过期分块、向量降级、Chat Completions 普通 / 流式与 Anthropic 工具编排，以及 OpenAI / Ollama 授权配置到索引和查询的协议桩链路。

TypeScript / Vite 构建和后端隔离打包通过；647 个应用 class 与隔离编译逐一一致，开发 JAR 已同步并核对 SHA-256。运行时落盘与静态便携审计通过。详细证据及跳过条件见[计划](../work/material-hybrid-search/plan.md#3-验证结果)和[QA](../test/QA_CHECKLIST.md#模块三十三笔记混合检索接入资料工具v082)。

工程验证不等于真实中文笔记的召回率、单轮准确度或 Token 收益评测。真实本地模型下载、真实供应商对照、Electron 实机及完整发行验收尚未执行；本次未修改版本默认值、打标签或发布。

## 4. 本版暂不纳入

- 长期记忆向量化、向量数据库替换、独立新 RAG 索引、重排器与跨语料混合搜索。
- 附件字节解析、自动读取整页、自动下载模型、绕过远程授权。
- 准确度或 Token 节省幅度承诺；研究依据与收益边界保留在全局清单。

施工材料保留在 `docs/work/material-hybrid-search/`，接口、架构和专题说明已同步本次已验证行为。
