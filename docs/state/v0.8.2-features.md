## 1. 本版目标

将既有笔记 embedding RAG 接入助手按需调用的 `search_materials`，让模型用自然语言查找笔记，取得相关片段与来源，必要时再按明确 ID 读取上下文。保留关键词查找、目录浏览和已有读取工具。同时接入联网 search / fetch，提供免配置默认服务、自定义供应商及模型内置 Web 工具优先选项。

同时修正助手的手动重试与模型持久化：重试复用原轮次，各会话独立记住自己的选择，新会话继承最近选择。

补齐当前会话的全局上下文占用、累计 Token 与缓存命中统计，并在「查看上下文详情」中展示当前会话卡片，以及按实际请求查看工具定义、调用参数和结果的组成估算。

## 2. F01 范围与行为

- `searchMode=hybrid|keyword`，默认 hybrid。非空的 `note/all` 查询、无 bankId 时复用 BM25 + 可选向量 + RRF；notebookId 限定笔记本。字面匹配优先，再补充语义候选。
- keyword 用于精确名称、编号、原文或符号，保留有界目录分页；空查询、其它资料类型 / 题库范围及明确 ID 读取不调用 embedding。
- 结果提供页面 / 笔记本定位、真实标题、来源链接和相关片段；同页分块合并，同次调用中的相同笔记片段去重。片段足够时可直接回答并引用，需要前后文才按 ID 分段读取。
- 默认每页 10 项、最多 20 项，每片段最多 240 Unicode 码点、每页总量最多 4,800；混合候选最多 80 项，达到候选上限明确告知。目录使用 60 KiB 软预算提前分页，nextOffset 按实际数量推进，保持共享 64 KiB 硬上限。
- 未配置向量时使用 BM25；已选空间但不可用、重建、覆盖不足、provider 不匹配、异常或超时则附降级说明并采用 BM25。分块哈希、页面存在与当前归属在返回前重新核对。
- 沿用现有工具开关、模型工具能力、授权、运行预算、停止和协议适配。工具参数及资料正文不进入持久化活动摘要；远程 embedding 仍须当前有效授权。
- 不新增数据库表、索引、模型下载或运行时写盘路径，所有落点继续经现有 APP_ROOT 便携策略。

## 4. F02 范围与默认方案

- 助手按需调用 search 查找网页与来源，再用 fetch 读取指定 URL 正文；两类工具均纳入现有全局工具目录、运行限制与停止机制。
- 无自定义配置时，免配置内置服务默认启用。首批自定义供应商为 **TinyFish、Tavily**，搜索与 URL 抓取可分别选择供应商，配置可保存并测试连接。
- 提供「优先使用模型内置 Web 工具」开关，默认关闭；按本轮受理时的模型、端点与协议分别判断能力。已适配 Anthropic 官方 Messages search / fetch 与 OpenAI 官方连接的隔离 Responses search；未知网关或不支持的能力使用所选服务，具体矩阵见[规格](../work/web-search/spec.md#原生联网支持矩阵)。原生调用共用阶段、输出、时间与用量账本。
- 用户已确认默认采用 **「内置自动」**：search 优先 Exa 官方免密钥 MCP，受限或不可用时有界尝试 Tavily Keyless；fetch 优先本地 HTTP 正文提取，正文不足时尝试 Exa fetch / Tavily Extract。Exa 当前匿名实际搜索返回 3 个来源，抓取也取得正文；Tavily 当前两项探测均返回日额度 429，不将单次成功当作持续服务保证。
- 「设置 → 工具」增加联网搜索、网页读取及服务配置；搜索与读取默认开启。助手输入栏增加地球按钮，快速控制同一对全局权限，全开时点击全关、全关或部分开启时点击全开；跨会话、重启保存。服务配置只在工具页编辑，开关即点即存，服务草稿保存 / 取消 / 测试；同一供应商共用密钥，不增加重复开关或重复供应商菜单。
- 匿名服务有独立限流，官方定位为探索与轻量使用；不承诺无限额度或长期服务保证。额度不足、超时与真实上游报错须可见，不通过轮换公共实例或内置共享密钥掩盖限制。
- 工具只接收必要查询或目标 URL，返回有界片段、正文和真实来源；不自动上传本地笔记、记忆或整段会话。配置、缓存与临时数据落在 APP_ROOT，URL 抓取限公开 HTTP(S)，不复用用户登录状态。

两项工具已进入统一普通 / SSE 编排，目录共 22 项、默认 18 开 / 4 关。服务配置使用 schema 19 的 `ai_web_settings`，同供应商共享加密密钥，revision 冲突不覆盖其它窗口。公开 URL、连接时 DNS、重定向、解压与内容预算已约束；单次远程尝试不超过 10 秒，整个工具不超过 20 秒，停止与安全拒绝不以降级掩盖。协议与接口见[规格](../work/web-search/spec.md)，已核对的供应商依据见[需求](../work/web-search/requirements.md)，界面行为见 [UI/UX](../work/web-search/ui-ux.md)。

后端相关 **46 类 / 443 项**，回归阶段 442 通过、1 项匿名探测按条件跳过，随后显式运行该探测并通过；最终 443 项均通过、0 失败、0 错误。前端相关 **17 文件 / 180 项：178 通过，2 项既有证据截图测试跳过**。TypeScript / Vite 构建与隔离后端打包通过，679 个应用 class 与同轮编译逐一一致，开发 JAR 已同步并核对 SHA-256。真实匿名搜索由 Exa 完成，fetch 在本地读取超时后由 Exa 取得正文；运行时落盘与静态便携审计通过。完整结果、命令与实测边界见 [QA](../work/web-search/qa.md)。

## 6. 会话原地重试与独立模型选择修正

- 手动「重试 / 重新生成」读取原提问与完整附件，在原回答位置生成新回答，复用原 turn / user / assistant ID；仅本次尝试使用新的 requestId。不发送额外的继续提示词，不新增用户消息或导航刻度，草稿与附件选择保持。
- 重试较早轮次以该轮为上下文截止点，不带入其后问答；保留原提问时间与位置，刷新原轮所在的驻留历史窗口。被拒绝时原回答保持可读，之后仍能重试。
- 同一 requestId 仍幂等；被替换的旧 requestId 返回 `TURN_SUPERSEDED` 并指向最新尝试。旧写入回执链继续可查，原轮附件重新加密，覆盖该轮的派生摘要 / 证据失效。原输入改变、内容已清理、上下文已重置或较早轮未保存回答位置时拒绝原地替换。
- 每个已有会话独立保存供应商对应的 modelConfigId 与思考档位。新会话继承最近选择，切回旧会话恢复其自身选择；其它会话的改选不覆盖当前会话。生成中与排队工作使用受理快照，手动标题生成和上下文占用也使用目标会话的模型。
- 选择与新会话继承默认在同一事务保存，重启后恢复；迟到轮询或保存响应不覆盖其它会话或更新的选择。旧空选择优先恢复最近实际模型，无法唯一匹配时只继承一次默认值。按钮样式沿用现有设计。

schema **20** 增加 `ai_chat_retry_receipt` 和 `ai_chat_session.model_choice_revision`，其余会话模型字段继续复用；数据库、升级快照和测试材料保持 APP_ROOT / 工作区落点。

后端相关 **26 类 / 335 项全部通过**；前端相关 **9 文件 / 143 项：141 通过、2 项既有证据截图测试跳过**，最终窗口 29 项复验通过。TypeScript / Vite 构建、后端隔离打包与两项便携审计通过，680 个应用 class 与同轮编译逐一一致，开发 JAR 已同步。覆盖原轮身份 / 位置 / 时间、完整附件、拒绝后的再次重试、较早轮上下文截止、容量事务、会话隔离与重启、配置快照、标题生成及旧库升级；详细命令和验收范围见[计划](../work/ai-conversation/plan.md#原地重试与会话独立选模修正2026-11-14)。

## 7. F04 上下文统计与逐请求详情

- 输入栏圆环使用 `current.tokens / contextWindow`，表示当前会话保留的全局上下文占用百分比。小卡片顶部为「上下文总量」和窗口进度，圆环悬停提示保留「估算」；下方增加「输入总量」，缓存命中旁标注「命中率」，未命中、输出及命中率保持会话累计实测口径。模型名移至左下，与「查看上下文详情」同一行；长模型名省略并可悬停查看，保留原按钮样式，移除旧注释。
- 详情标题改为「上下文」，在上下文浏览器上方加入「当前上下文」卡片，展示当前模型、占用总量 / 窗口、比例、分段进度及紧凑分类。卡片与圆环共享会话统计，分类合计等于当前总量，不随历史请求选择变化；旧额外组成缺少有效分类时归入「其他内容」。原底部「本轮累计用量」与 done 用量回退移除，累计仍在小卡片 / 账本保留。
- 全局正文按当前代数、未清理内容逐行计一次，包括所有保留提问 / 回答及 RECEIVED 插话；不受 500 条驻留、32 轮扫描或单请求预算限制。流式回复实时增长，终态改用存储正文，原地重试替换旧回答。有效摘要只替代已覆盖旧轮，最近两轮和 coverage 缺口保留；独立思考列按现有历史重放规则不计入。
- 固定规则与当前模型可用工具定义只算一次；当前轮保留的工具往返、注入资料、图片和续接指令也只计一份。新加密元数据记录版本化数值，旧消息按需解密并仅缓存数字；无法读取的旧内容显示已知下界。最近请求实测与累计输入独立，不能用它们补足窗口占用；超过窗口时保留实际总量 / 百分比，图形封顶 100%。
- 会话 / 本轮累计共用请求账本，包含所有对应 CHAT 请求、工具往返、原生联网、自动恢复及原地重试旧回执；排除其它会话、标题、维护和未发送预留。正文清理、上下文换代和 500 条驻留限制不扣掉已发生用量。
- OpenAI 输入已包含缓存时不二次相加；Anthropic 输入加上独立缓存读写，缓存写属于未命中。缺失保持 null，部分实测展示 `≥`；累计输入或缓存不完整时不计算命中率。旧缓存口径只在原始桶 / 次数 / 终态与独立日账本完整吻合时迁移，无法核实则保持未知。
- 展开详情参考 [dsh-context](https://github.com/bowenliang123/dsh-context)，按请求选择、真实时刻、分类展开和前次请求对比查看组成。工具定义、调用参数、结果分别列出估算与数量，明细按占用排序并标记请求内消息位置；对比包括增加与移除的分类。
- 分类从各协议最终请求体提取，本地中日韩加权估算标为 `≈`，实测输入 / 输出单列，不把估算缩放成精确收费分项。图片采用固定预留，不按 base64 长度计 Token。
- 最近 50 次已发请求优先展示，更早请求按同轮游标分页；选定旧请求后不会被刷新替换。运行中只读刷新数值，关闭或换轮后忽略迟到响应，来源正文仍须显式逐条对照；顶部当前卡片独立刷新，不依赖旧账本可用性或最后一次 done。
- schema **21** 增加缓存桶包含标志和每次请求的组成摘要，最多 256 项 / 32 KiB；省略明细仍计入分类总数与总量。摘要只保存分类、工具名、模型、位置与数字，原始参数、结果、提示词和附件不复制落库。旧请求未保存的组成不会重建或借用新请求。
