# 模型必填容量 UI/UX

> 2026-11-10 用户直接指定的调整，随新增资料工具一并实现。

- 模型设置固定展示「上下文与输出上限」，上下文窗口、最大输出 Token 均为必填正整数；最大输出不能大于上下文窗口。不再藏于“可选”折叠项。
- 删除最大输入字段。输入与输出共享已填写的上下文窗口；仍保留正常 token 估算、输出预留与应用全局运行预算。
- 明确选择预设时自动填入预设容量；普通编辑模型 ID 不改变任何已填写项。
- 从供应商发现模型时，预设未给出完整容量的模型需先补全两个值，再开始自动验证；不能用猜测容量绕过必填。
- 旧模型缺值时显示「待补全」，可打开设置补填；禁止应用、测试和正式对话。保留原配置与用途绑定，不静默补一个保守窗口。
- 已填写的真实容量仍正常使用；历史 maxInputTokens 不再生效，后续保存时移除。
