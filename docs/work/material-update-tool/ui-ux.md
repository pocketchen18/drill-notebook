# 修改学习资料工具 UI/UX

> 2026-11-10 用户授权继续实现。沿用现有工具活动和资料来源导航，不新增常驻界面或确认弹窗。

- 用户要求修改资料后，模型先定位并读取已保存目标；只修改明确委派的字段。搜索结果和当前页面草稿不能替代正式读取。
- 活动显示「修改学习资料 · 执行中」，成功后显示「已更新」及「查看资料」。不跳离当前聊天，人工仍在原业务页使用该资料。
- 未提供字段保持原样；重试显示「已处理，未重复修改」，无实质变化显示「内容未变化」。保存后又被编辑的对象不因重试覆盖回旧内容。
- 目标在读取后有变化时显示「资料已变化，请重新读取后核对」。模型先核对用户意图，不自动强制覆盖。删除、取消、保存未确认分别如实说明。
- 笔记正文采用精确文本替换或追加 Markdown，保留不相关的富文本、图片、文件和题目快照。提交时的当前笔记仍有未保存草稿时，先提示保存草稿再修改。
- 更新成功刷新对应目录；干净的打开笔记刷新正文，尚有本地编辑、保存中或保存失败的内容保持原样。普通自动保存和后台 keepalive 确认后及时清除草稿状态，下一次提问可正常委派修改。知识点仅修改当前卡片，不改原文 / 总结档案；错题修改原题，不动真实统计。

```text
▾ 已更新学习资料
  ✓ 修改学习资料    已更新
    保存位置        查看资料 ↗

已补充 [导数](资料链接) 的说明，其他内容保持原样。
```
