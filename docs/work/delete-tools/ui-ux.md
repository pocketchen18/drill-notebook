# 删除工具与全局工具设置 UI/UX

> 2026-11-10：删除工具及全部内置工具的独立开关已实现并完成专项验证；真实供应商与 Electron 实机仍待验收。验证结果见 [QA](../../test/QA_CHECKLIST.md)。

## 设置 → 工具

- 顶层 Tab「工具」排在「AI 对话」之后，展示全部 20 个内置工具，按学习资料、记忆、会话、删除四组排列。16 个非删除工具默认开启，4 个删除工具默认关闭；不增加尚未实现的联网搜索配置。
- 开关即点即存，不设草稿和保存按钮；保存期间禁用开关，失败保留服务端状态并提示。「恢复默认」开启非删除工具、关闭删除工具，全部为默认值时禁用。
- 升级保留已有选择；只有尚未保存偏好的项使用默认值。设置对所有供应商、模型和会话生效；开启某项不自动开启其它工具，记忆工具还需启用记忆功能，模型也需支持工具调用。
- 说明只有一句话；每项一行名称加一句用途，不写大段文案。

```text
工具                                             [恢复默认]
选择 AI 可以使用的内置工具，对所有模型和会话生效。

学习资料
  读取当前页面    读取当前页面已展示的内容和未保存的笔记草稿。 (● )
  查找学习资料    按关键词查找笔记、知识点、题库和题目。       (● )
  读取笔记        查看笔记本目录与笔记页正文。                 (● )
  读取知识点      查看知识点的当前内容、原文或总结。           (● )
  读取题库        查看题库目录与题目详情。                     (● )
  读取错题        查看错题列表、题目和作答统计。               (● )
  新增学习资料    新建学习资料，或将题目加入错题本。           (● )
  修改学习资料    修改已有笔记、知识点、题库或题目。           (● )

记忆
  检索记忆 / 读取记忆 / 新增记忆 / 更新记忆                  各自 (● )
  还需在记忆设置中启用记忆功能。

会话
  查找历史会话 / 读取会话 / 新建会话 / 发送消息              各自 (● )

  默认关闭；开启后 AI 仅按你的明确要求删除，删除后无法恢复。
  删除记忆        删除指定的长期记忆。                          ( ○)
  删除会话        删除指定的历史会话及其消息。                  ( ○)
  删除学习资料    删除笔记本、笔记页、知识点、题库或题目。      ( ○)
  移出错题本      将题目移出待巩固，不删除原题。                ( ○)
```

- 开启从下一轮对话生效；关闭会阻止尚未开始执行的调用，不撤销已经执行的操作。
- 选择模型预设、恢复「AI 对话 → 运行限制」或其他设置都不改变这些开关。

## 对话中的表现

- 沿用现有工具活动，不新增确认弹窗或常驻界面。用户明确要求删除 → 模型先查找 / 读取目标 → 调用删除工具 → 活动与回答说明真实结果。
- 活动名称：「删除记忆 / 删除会话 / 删除学习资料 / 移出错题本」。已删除的对象不再提供「查看资料」「打开会话」；移出错题本保留「查看原题」。
- 工具未开启时，模型说明该能力未开启、可在「设置 → 工具」开启后重新提出，不声称已执行。关闭删除工具时仍禁止用修改或清空内容冒充删除。
- 所有工具均关闭时仍可正常聊天；运行中关闭读取、新增、修改或删除工具，活动统一显示「工具已在设置中关闭，未执行」。

| 结果 | 活动文案 |
|---|---|
| 资料已删除 | 已删除 |
| 笔记本 / 题库仍有内容且未确认一并删除 | 其中仍有内容，未删除 |
| 当前会话的记忆范围绑定该笔记本 | 当前会话绑定该笔记本，未删除 |
| 读取后资料已变化 | 资料已变化，请重新读取后核对 |
| 重复调用 | 已处理，未重复删除 |
| 已移出待巩固 / 本就不在 | 已移出错题本 / 已不在错题本中 |
| 会话已删除 / 正在使用 / 是当前会话 | 会话已删除 / 目标会话正在回复或有待发送消息，未删除 / 不能删除当前会话或其上游会话 |
| 记忆已删除 / 找不到 / 多条匹配 | 已删除 1 条 / 未找到待删除的记忆 / 需明确要删除的记忆 |
| 执行前开关被关闭 | 工具已在设置中关闭，未执行 |
| 结果未确认 | 删除结果未确认，请核对 |

```text
▾ 已删除学习资料
  ✓ 读取笔记        本次读取 1 项
  ✓ 删除学习资料    已删除

已删除笔记页「旧草稿」，同一笔记本的其他页面没有变化。
```

- 删除成功后刷新对应目录。被删除的笔记页若在本地还有待保存草稿，前端直接丢弃，不再向已删除页面保存；当前打开的页面被删除时回到同一笔记本的其他页面。
- 删除记忆后刷新记忆列表与计数；删除会话后刷新会话列表。当前会话不能被自己删除，所以不会出现聊天窗口突然消失。

## 本轮实现边界

1. 「移出待巩固」做成独立工具 `remove_wrong_question`，与「删除原题」（`delete_material` 的 question 类型）分开，共四个工具。
2. 设置入口沿用「工具」Tab，补齐全部现有内置工具，不扩展新工具或搜索服务配置。
3. 不加确认弹窗：保护依靠默认关闭、读取版本校验、非空容器的显式 `cascade`，以及模型在范围不清时先向用户确认。
4. 由其他会话派发的任务不提供删除工具，删除必须出自用户在该会话中直接提出的消息。
5. 会话的记忆范围绑定某笔记本时，不能在该会话内删除这本笔记本（否则删除会重置本会话上下文并中断当前回答）。
