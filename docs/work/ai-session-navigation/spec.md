# 会话导航 MVP 实现规格

> 2026-11-08；基于已确认 [UI/UX](ui-ux.md)。只实施导航和标题；跨会话工具待用户验收并提交 Git 后另起切片。

## 数据与状态

- schema 12 在 `ai_chat_session` 增加 `session_ref`（随机 128 位引用，以 32 位小写十六进制表示、唯一）、`title_source`（temporary/manual/ai/legacy）、`title_status`（pending/idle/generating/ready/failed）、`title_revision`（从 0 递增）。链接为 `drill-notebook://session/<session_ref>`；改名、重启不变，不注册系统协议。
- 迁移为旧会话补引用，保留标题。有消息的旧会话标 legacy/idle，绝不批量生成；空白默认名可保持 temporary/pending。重启把残留 generating 转 failed，不自动重试。
- 新默认名会话为 temporary/pending，自定义名字为 manual/idle。首次发送填首问摘录作为临时名，不改变人工名。
- 第一个完整且持久化成功的问答（COMPLETED、有用户与助手正文）才触发自动生成。失败或中断不触发；之后首次成功可触发。自动失败后只接受手动重试，后续问答不会反复请求。
- 生成认领和提交均以 revision 做条件更新；人工保存递增 revision、标 manual/idle，迟到结果被丢弃。删除后更新零行，不复活会话。所有标题写入不改变 `updated_at`、history_revision 或排序。

## 后端闭环

- 会话列表与单项增加 `sessionLink`、`titleSource`、`titleStatus`、`titleRevision`、`canGenerateTitle`。完整问答资格从已持久化轮次计算。
- `POST /api/ai/sessions/{id}/title`，请求 `{expectedRevision, overwriteManual?: true}`，返回已认领会话（202）。无完整问答、重复任务、版本变化、未确认覆盖人工名分别返回明确错误。重命名继续用原 PUT。
- 自动生成在聊天持久化成功后提交到有界后台执行器；不等待标题网络请求。每个会话最多一个任务；只传首个完整问答的正文片段（每段最多 4000 字符），不带附件、工具或整段历史。
- 自动任务沿用本轮模型配置快照，手动任务用当前应用模型；复用现有双协议客户端、解密和连接占用保护。解锁材料从进程会话取，不进 URL。60 秒超时、最多 1024 输出 token、禁工具和额外思考；不重试、不输出正文到日志。
- 用量复用 CHAT 分类，以 `session-title:<ref>:<revision>` 独立 operation 标识；厂商未返回用量则记 unknown。任务受活跃句柄保护，避免维护清扫误结算。
- AI 标题仅接受非空单行简短正文，去外围引号/标题前缀；多行解释、截断或异常输出作为失败保留原名。人工标题不截断。
- 会话列表允许为空，读取列表/旧消息及正常启动不创建占位会话；初始化仅在确有未归属的旧消息时建立迁移用会话。允许删除最后一条，保留正在回复的会话保护。旧客户端实际发送时的默认会话兼容仍保留。

## 前端边界

- 独立会话导航组件负责浮动列表、菜单、输入草稿及确认。所有动作显式绑定目标 ID；非当前会话操作保持当前正文、输入和滚动位置。
- 复用现有会话查询；只在存在 generating 时短轮询，后台任务完成即停止。首轮结束沿用会话列表失效刷新。后台刷新不覆盖重命名草稿。
- 二级菜单 portal 到 body，视口夹边、向左展开和窄视口返回。窄视口仅点击/键盘进入子菜单，不因悬停替换正在点击的父项。键盘、IME、错误保留与焦点按 UI/UX 验收。
- 剪贴板实际成功后反馈；失败弹可选文本。链接在本轮只能复制，工具读取尚未实现，不宣称可分享或已读取。
- 新会话页是显式前端状态（没有会话 ID），与首次加载时的自动选择区分；新建入口只进入该页，已在该页时保留草稿，不创建、不复用数据库空会话。禁用该页的当前会话菜单，历史查询不发请求、不显示加载中。
- 首次有效发送完成输入/配置校验后，调用既有创建接口，再将同一份输入交给聊天轮次；同步锁防双击/回车重复创建，创建期间禁用编辑和导航。创建失败保留草稿/附件；聊天请求已经发出后失败保留该会话供重试，不再次建会话。新会话选中并完成 React 更新后才启动首轮，防止丢失快速返回的流式事件。
- 导出使用目标 ID；删除失败保留确认。删除当前成功后清空正文、草稿、附件与上下文检查器，进入未保存的新会话页；列表刷新不得改选其它历史会话。删除非当前会话不创建或切换会话，允许列表为空。

## 验证

覆盖标题触发/失败/重试、人工优先、删除、重启与迁移、排序不跳；前端非当前菜单动作、草稿/IME、嵌套键盘菜单与复制失败。使用隔离 APP_ROOT 和本机模拟上游验收，不动真实运行数据或发行打包。
