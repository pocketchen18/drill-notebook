# 笔记混合检索接入资料工具：需求

> v0.8.2 F01，已实现并通过工程验证（2026-11-14）。版本状态见[功能清单](../../state/v0.8.2-features.md)，实现与验证见[规格](spec.md)和[计划](plan.md)。

## 1. 目标

复用既有 embedding RAG，让助手的笔记查找具备词法与语义互补能力。搜索先交付相关片段和明确来源，需要前后文时才读取完整页面的局部内容，减少不必要的补查与正文传输。

## 2. 功能需求

| 编号 | 需求 | 验收口径 |
|---|---|---|
| R01 | 默认混合检索 | `search_materials` 的非空 note/all 查询、无 bankId 时调用既有 BM25 / 可选向量 / RRF |
| R02 | 保留精确路径 | keyword 保留字面匹配和分页；空查询、其它类型 / 题库范围、ID 读取不调用 embedding |
| R03 | 遵守范围 | notebookId 生效；返回前核对当前页面归属、存在及分块哈希，排除孤立 / 移动 / 陈旧结果 |
| R04 | 有效片段与来源 | 摘要来自命中块，提供 pageId/notebookId/title/sourceLink；同页合并，多来源重复笔记片段不重复正文 |
| R05 | 有界结果 | 每页默认 10、最多 20，每片段 240 码点；候选最多 80；字符和 UTF-8 字节预算均有效 |
| R06 | 真实分页状态 | 达到候选上限告知 searchLimited；hasMore 只表示已有候选可续页；字节提前分页按实际行数推进 |
| R07 | 向量容错 | 未配置向量是正常 BM25；已配置但不可用 / 超时返回 BM25 与 notice，工具继续工作 |
| R08 | 隐私与工具约束 | 复用有效远程授权、工具开关、预算及停止；正文不进入活动摘要，日志不记录查询或笔记内容 |
| R09 | 便携与兼容 | 不新增 schema、索引或运行时落点；原有兼容检索、目录和读写工具继续通过回归 |

## 3. 交互要求

沿用助手现有工具活动与资料来源入口；设置中的工具说明明确笔记支持混合检索，embedding 配置继续放在「设置 → 嵌入与检索」。无需新增按钮或面板。用户已授权实施此前规划的工具增强，界面范围见[UI/UX](ui-ux.md)。

片段足够时模型直接使用实际标题和 sourceLink 引用；目录或片段不能假称全文。需要上下文再使用明确 ID 与 version 分段读取，STALE 时重新取得目标。

## 4. 边界

本次只接入笔记。长期记忆保持现有词法工具与标题列表；知识点、题库、题目和错题保持原查询路径。不新增重排器、向量库、附件解析或自动模型下载。

公开经验支持词法与语义检索互补，但本项目尚未进行真实供应商准确度 / Token 对照评测，相关收益属于目标。研究出处见[全局决定](../../features.md#笔记混合检索接入资料工具v082已实现)。
