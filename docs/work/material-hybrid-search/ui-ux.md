# 笔记混合检索接入资料工具：UI/UX

> v0.8.2 F01，沿用现有助手与设置界面，已实现并通过相关前端 / 工具链回归（2026-11-14）。本切片属于工具行为增强，无新增布局或草图；需求见[requirements.md](requirements.md)。

## 1. 入口

| 位置 | 展示与操作 |
|---|---|
| AI 助手 | 用户正常提问，由模型按需要调用现有 search_materials；仍可从工具活动查看真实执行状态和资料来源 |
| 设置 → 工具 | 保留现有独立开关；说明更新为「按关键词查找学习资料；笔记支持可选向量与关键词混合检索。」 |
| 设置 → 嵌入与检索 | 沿用当前本地 / OpenAI / Ollama 来源、授权、模型下载与索引状态控件 |
| 回答内来源 | 使用实际标题和资料链接；点击进入原笔记页面，沿用已支持的跨窗口定位 |

## 2. 查询与结果状态

| 状态 | 模型可见信息与预期反馈 |
|---|---|
| 混合查询成功 | 相关片段与来源定位，同页只作为一项；片段足够时直接引用 |
| 需要更多上下文 | 用返回的 pageId 调用 read_notebook，沿用分段、version 与来源入口 |
| 精确查找 / 浏览目录 | 使用 keyword 或空 query，保持字面匹配与分页，不触发 embedding |
| 无向量配置 | 正常采用 BM25，不显示未配置错误，不提示自动下载 |
| 已配置向量不可用 | 工具结果包含 retrievalNotice，BM25 结果继续可读；不把向量故障当成整个回答失败 |
| 候选有上限 | searchLimited 与 notice 提示缩小范围、细化查询或改用 keyword；不能声称已查遍所有笔记 |
| 还有候选 / 字节预算提前分页 | hasMore 与 nextOffset 按实际结果续页；byteLimited 区分字节预算，避免丢项 |
| 无匹配或目标失效 | 沿用 NO_MATCH / NOT_FOUND / STALE 等现有状态，不生成虚构来源 |

## 3. 展示边界

原始工具参数、查询与笔记正文只用于本轮工具结果。历史活动继续只展示安全状态、数量与来源，长期记忆开关不控制资料检索。相同笔记片段保留所有来源链接，后续条目通过 snippetDuplicateOf 指向已展示片段。

不把片段自动并入当前页面正文，也不要求片段之后必读整页。工具权限及运行设置仍由现有控件管理，不增加重复操作入口。

## 4. 验证

工具设置、助手、页面快照与 embedding 设置相关前端 **4 文件 / 38 项**通过，TypeScript / Vite 构建通过。后端真实工具编排验证了引用定位与按 ID 续读；本轮未执行新的 Electron 视觉或读屏验收，详见[计划](plan.md#3-验证结果)。
