# AI 对话：失败重连、会话跳转与模型选择 UI/UX

> 状态：已实现并通过工程验证（2026-11-13）。按用户最终修订，保留轮次与时间，用粗体提问、浅色回答区分；回答最多三行，刻度固定间距、整组居中，支持滚轮及悬停动态展开。预览整卡点击定位，报错直接显示一次。范围和 Codex 重试基线见 [v0.8.1 功能清单](../../state/v0.8.1-features.md)，视觉沿用[全局设计规范](../../DESIGN.md)。本版交互共用本文；[交互草图](conversation-preview.html)演示重连与跳转，既有 [v0.8.0 窗口设计](../../archive/v0.8.0/ai-window/ui-ux.md)保留归档口径。

2026-11-14 已同步 v0.8.2 的原地重试与会话独立选模修正；现有按钮样式和导航布局沿用原设计，行为与验证见[规格](spec.md)和[计划](plan.md#原地重试与会话独立选模修正2026-11-14)。

## 1. 布局与入口

沿用独立助手窗口、左侧会话栏、正文和底部输入区。失败重连放在正在生成的回答末尾；会话跳转使用正文右侧留白。设置仍在主窗口的「设置 → AI 对话 → 运行限制」。

```text
┌ AI 助手 ───────────────────────────────────────────────┐
│ 会话栏       │ ☰  固定  导数与积分复习        正在重连 ⋯ │
│ 新建会话     ├─────────────────────────────────────────┤
│ 查找会话     │ 用户提问                            ─   │
│              │ 助手回答                            ─   │
│ 当前会话     │                    ┌ 第 4 / 18 轮 ┐  ━   │
│ 其他会话     │                    │ 提问片段      │  ─   │
│              │                    │ 回答片段      │  ─   │
│              │                    └───────────────┘  ─   │
│              │ ↻ 正在重新连接 2/5             停止     │
│              │ stream disconnected before completion  │
│              │ 0.8 秒后重试                            │
│              │                           回到最新 ↓    │
│ 存储 · 设置  ├─────────────────────────────────────────┤
│              │ 输入草稿                                │
│              │ ＋ 页面  上下文        模型  档位 停止 ↑ │
└──────────────┴─────────────────────────────────────────┘
```

右侧刻度属于消息阅读区，不进入输入区；打开并排详情栏时随正文边界移动。预览卡片向左展开。

## 2. 失败重连反馈

### 外观

- 在该轮回答末尾显示紧凑反馈，已有正文、思考过程和工具活动保留。空回答也有同一反馈位置。
- 首行是重连图标、状态及次数，右侧为「停止」文字按钮。使用 13px UI 字号和等宽数字；图标 14px，间距 8px。
- 第二行保留上游具体报错。状态码仅在实际取得时出现，正文采用 12px 字号；长英文、网址和连续字符可换行。
- 等待时显示剩余时间，例如「0.8 秒后重试」。正在发送重试请求时显示「正在连接…」，没有准确截止时间时不编造倒计时。
- 自动恢复阶段使用警示色图标和细侧线，背景仍为正文表面；停止后为次要文字，最终失败使用错误色图标。状态始终有文字，不只靠颜色或动画。
- 正文反馈的「停止」与输入区已有停止按钮停止同一轮。停止后保留部分回答、具体错误和已完成的工具结果。
- 自动重试期间保持会话处于运行中；输入区继续允许输入、添加附件和沿用既有队列行为。顶栏状态用「正在重连」或「等待网络」，不反复弹 toast。

### 状态与操作

| 状态 | 主行示例 | 补充信息 | 可用操作 |
|---|---|---|---|
| 请求暂时失败 | 请求重试 2/4 | 上游状态码与正文；下一次等待时间 | 停止 |
| 流式回答中断 | 正在重新连接 2/5 | 流中断的具体错误；等待或正在连接 | 停止 |
| 断网，默认持续等待 | 等待网络恢复 · 已重试 2 次 | 实际连接失败原因；例如 20 秒后重试 | 停止 |
| 断网，用户设置有限上限 | 等待网络恢复 2/8 | 同上 | 停止 |
| 重连成功 | 继续生成中的正常回答 | 临时状态结束；不常驻成功横幅 | 沿用生成中的操作 |
| 达到上限 | 重新连接失败 · 已重试 5/5 | 保留最近的具体报错 | 沿用已有重新生成 |
| 已停止 | 已停止重新连接 · 已重试 2 次 | 保留部分回答和最后错误 | 沿用已有重新生成 |
| 不可恢复错误 | 无法继续生成 | 实际鉴权、额度或配置错误，不显示虚假的重试进度 | 沿用已有重新生成；按现有配置错误入口处理 |
| 原轮次预算到期 | 本轮运行时间已用尽 | 保留当前恢复次数、部分回答和真实停止原因 | 沿用已有重新生成 |

初始请求不计入重试数。次数只在真正发起一次恢复请求后增加，倒计时不会提前占用下一次计数。不同重试层级分别展示实际计数；由请求重试进入流式重连时更换明确标签，不合成一个虚假的总上限。纯断网持续等待不显示「/5」或「/∞」。

成功后恢复正常消息流，不追加另一条用户问题；成功完成时清除临时恢复反馈，不常驻重连横幅。停止或失败的原因随原回答加密保存，零正文也保留可读原因。手动「重试 / 重新生成」在原回答位置生成，原提问只保留一份，草稿和待发附件保持；操作较早轮次时阅读窗口留在原处，之后的问答顺序不变。准备或受理失败时恢复原回答和关联，继续允许重试。

### 报错直接显示

直接显示可取得的状态码、错误代码和安全报错，按原行换行；同一报错只展示一次，不附加展开、收起按钮。缺失字段省略，不把具体报错统一改写成「网络异常」。

沿用既有脱敏规则，排除密钥、请求头、工具原始参数和结果；这里展示的是供应商错误，不是原始请求日志。报错展示不触发工具或模型调用，也不抢焦点。读者已上翻时，重连状态变化保持阅读锚点。

## 3. 设置：运行限制中的失败重连

在现有预算字段之后增加「失败重连」分组，继续使用同一份表单和统一的「恢复默认 / 取消修改 / 保存」。普通请求和回答中断的次数分别设置，以保留已核实的 Codex 默认行为；等待间隔由策略计算，不新增间隔输入框。

| 字段 | 控件与默认 | 范围与说明 |
|---|---|---|
| 请求重试上限 | 数字输入，默认 4 次 | 0–100 的整数。请求暂时失败时最多再试多少次；0 关闭这类自动重试 |
| 回答重连上限 | 数字输入，默认 5 次 | 0–100 的整数。回答中途断开时最多重新连接多少次；0 关闭这类自动重连 |
| 断网等待 | 下拉选择，默认「持续重试」 | 可选「持续重试 / 限制次数」。持续重试仍受整轮预算约束，并始终可停止 |
| 断网重试上限 | 选择「限制次数」时出现数字输入 | 0–100 的整数；0 关闭断网自动重试。由持续切换为有限且没有旧值时，草稿先填 5 次，保存后才生效；恢复默认回到持续重试 |

分组说明：「短暂故障会自动重试。等待时间逐步延长，服务端指定等待时间时优先遵守。所有设置保存后从下一轮开始使用。」本版普通请求与流式重连均从 400ms 起翻倍等待，保留约 ±10% 抖动；Codex 原始 200ms 单独记录。确切默认次数和退避序列以[版本清单中的源码基线](../../state/v0.8.1-features.md#已核实的-codex-默认策略)为单一来源。

- 数字单位紧贴输入框，错误在字段下方显示「请输入 0–100 之间的整数」，禁止以空值、负数、小数或超限数保存。
- 「持续重试」时不展示禁用的空数字框；切换模式不立即保存，也不改变正在运行的轮次。
- 保存成功沿用「已保存，从下一轮对话开始生效」。失败保留草稿和具体原因；后台刷新不覆盖未保存的输入。
- 恢复默认只更新当前草稿，取消修改还原已保存值；离开仍沿用现有未保存修改保护。原预算字段及它们的约束保持现状。
- 宽设置页为两列字段，窄页为一列；「断网等待」及其条件字段在同组内连贯展示。

## 4. 会话内对话跳转

### 刻度与定位单位

使用消息区右侧的一条纵向细刻度。绘制区域约 24px 宽，完整交互区域至少 44px 宽；离右侧原滚动条保留间距。它利用正文留白，正文阅读宽度上限仍为 760px。

- 一个定位单位对应一条已进入当前会话的有效用户提问及其回答。刻度按提问时间从上到下排列；最后一轮代表最新提问。
- 工具调用和思考过程不新增刻度。当前轮的插话仍属于该轮；待发送队列尚未成为用户消息的条目不提前显示。手动重试与重新生成复用原提问和回答位置，不增加定位点，原轮次编号与提问时间保持。
- 平时普通刻度为 6 × 2px、透明度约 0.4；当前阅读位置为 8 × 3px 的强调色线。悬停或键盘聚焦后，所选刻度加长到 24px，距离 1–4 轮的邻近刻度依次为 20 / 16 / 12 / 8px，并逐渐变淡；其余仍为短线。离开平滑收回，宽度、透明度与颜色沿用全局 120ms 过渡。当前阅读位置与预览位置分别表达。
- 当前阅读位置由正文实际可见的提问 / 回答决定，滚动、跳转和新消息后更新；悬停预览本身不改变它。
- 空会话与只有一轮的会话隐藏刻度。刻度中心间距固定 10px，上下各留 8px；整组高度随可见数量变化，并在消息阅读区垂直居中。13 轮时高 136px，64 轮时高 646px，少量轮次不拉伸铺满。容量按父消息区的可用高度计算，最多 64 个连续逐轮刻度；高度充足时能展示 50 个以上，矮窗口按高度减少。窗口缩小或放大时保持已打开预览的所选刻度可见；不把全会话压缩合并成少数刻度。
- 超出可见数量后，鼠标在刻度区或预览卡片上滚轮上下翻阅隐藏轮次，首尾停止。翻阅只更新连续刻度窗口与预览，不滚动聊天正文、不自动定位；当前阅读轮次仍保持。方向键与 Home / End 可以选择全会话序列，只有一个键盘定位停靠点。

刻度整体作为可键盘操作的单一定位控件；视觉细线不制造额外小按钮。指针按固定间距选择最近轮次，键盘继续精确移动到相邻轮次。鼠标点击直接定位，不强制聚焦或留下整条导航的蓝框；Tab 进入后保留清晰的键盘焦点提示。

### 预览卡片

首次悬停约 150ms 或键盘聚焦后显示预览，向左展开；连续移动不重新延长首次等待。打开后每个动画帧最多更新一次，并使用最后的指针目标；同轮已加载或正在加载时不重复读取预览。从刻度移到卡片时保持打开，离开两者约 180ms 后关闭，并取消待执行的悬停更新。卡片宽 320px，上限随正文可用空间收窄，距离刻度 8px；垂直位置限制在消息区内，不遮挡顶栏或输入区。

| 区域 | 展示 |
|---|---|
| 顶行 | 同一行显示「第 4 / 90 轮」与该轮真实提问时间，按系统时区显示；缺失或不可解析时不显示时间；不加完成状态或分割线 |
| 提问 | 粗体、正文色，最多 2 行；纯图片 / 附件提问使用文字占位 |
| 回答 | 浅色、普通字重，最多 3 行；没有正文时显示正在生成或暂无回答 |
| 长文本 | 按实际排版截断，末尾明确显示三个点 `...`，不截断 Unicode 码点 |
| 未加载的旧记录 | 「正在读取预览…」；失败显示实际原因，点击整卡可重试定位 |

卡片使用不透明正文表面、8px 圆角、轻阴影和 12px 内边距。提问与回答只靠字重和浅色区分，不增加两种标签；文本左对齐。片段去掉 Markdown 标记，不渲染工具日志、原始参数或大段代码，不新增模型调用。

长文本先测短前缀，截断结果按原文及宽度、字体、行数等布局条件缓存；回到相同片段时复用，布局变化时重新计算。更新预览期间保持文本节点挂载，只显示与目标轮次匹配的正文，加载中点击仍定位当前目标。

点击刻度或预览卡片整体立即定位到同一轮提问，卡片不附加跳转按钮。触屏先选择刻度并打开预览，再点击卡片定位。

### 跳转、分页与生成

- 提问对齐到消息区顶部下方约 24px，短暂用选中底色标明目标；只滚动消息区，不滚动整个窗口，也不抢输入框焦点。
- 需要的旧消息尚未驻留时先显示定位加载状态，成功后再定位；失败保留原阅读位置并显示原因，可重新点击。按目标消息 ID 加载有界历史阅读窗口，最多驻留 500 条；页大小与轮次定位契约见[规格](spec.md)和[接口](../../state/api-contracts.md)。
- 跳到旧对话后暂停自动跟随流式输出；已有「回到最新」继续显示，有新内容时沿用小圆点提示。点击后回到末尾并恢复跟随。
- 保持当前会话、输入草稿、附件、工具运行和队列状态。切换会话关闭预览，重建当前会话的刻度与阅读位置，不复用上一会话的目标。
- 正文选择文字时沿用现有「复制 / 引用」浮层；浮层出现期间隐藏跳转导航与预览，结束后恢复。

## 5. 窄窗口、详情栏与键盘

| 布局 | 跳转与重连表现 |
|---|---|
| 宽窗口，详情并排 | 刻度跟随正文右缘；预览只在正文范围展开，不进入详情栏 |
| 中等窗口，详情覆盖正文右侧 | 详情覆盖时暂时隐藏刻度与预览，关闭后恢复；后台生成状态继续更新 |
| 小于 760px，会话栏收起 | 保留右侧定位区；预览按正文宽度收窄，重连首行和停止操作允许换行 |
| 窄窗口打开会话浮层或全屏详情 | 暂停背景刻度交互并关闭预览，关闭浮层后恢复 |
| 200% 缩放或触屏 | 使用窄布局，操作目标至少 44px；不用 hover 作为唯一入口 |

| 按键 | 定位控件获得焦点时 |
|---|---|
| 上 / 下 | 逐轮选择并预览，不立即滚动正文 |
| Home / End | 选择第一轮 / 最新一轮并预览 |
| Enter / Space | 跳到所选轮次 |
| Escape | 关闭预览，保留焦点；不停止生成 |
| Tab | 沿正常顺序进入预览卡片或离开；焦点离开刻度与预览后关闭卡片 |

重连状态采用礼貌播报，只播报阶段或次数变化，不逐帧播报倒计时。最终失败和字段校验提供可读提示。各按钮有明确可访问名称；焦点边框、错误文字与普通文字在明暗主题下保持可辨识。减少动态效果时取消刻度过渡和目标闪动，跳转使用即时定位。

## 6. 草图与设计检查

[草图](conversation-preview.html)使用 90 轮虚拟对话和本地状态，展示超过 64 个刻度后的滚轮翻阅、静止 / 悬停动态效果，以及默认重连、请求重试、断网等待、恢复完成、次数耗尽与不可恢复错误；可切换状态、主题、宽窄布局、详情栏及设置页。正文可滚动，右侧可预览 / 跳转，「停止」「重新生成」和设置表单只演示交互。

草图只演示当前轮的停止与重新生成，旧轮操作和现有预算字段作为样式参考；既有预算值是虚拟示例，不代表配置变更。草图不连接真实供应商，不写应用数据。

草图的离线交互检查与产品自动化测试分别执行，结果见[实施计划](plan.md)。后续实机观感验收关注：

1. 上游报错、实际次数和等待状态能同时读清，停止始终可到达。
2. 请求 / 流式 / 断网三种默认状态与设置字段对应；0 和持续等待含义清楚。
3. 重连反馈留在原回答，部分内容和输入草稿保持。
4. 右侧刻度固定间距、整组居中，预览向左展开；当前阅读位置与悬停位置可区分，鼠标移入后响应顺畅。
5. 点击定位后不被新输出拉回，回到最新入口继续工作。
6. 长历史、键盘、窄窗口和详情覆盖有明确行为；预览不挡输入。
7. 明暗主题、长英文报错和字段错误没有横向溢出。

## 7. 模型选择与导入绑定

AI 助手输入区的模型按钮回显当前会话保存的实际模型，菜单按供应商分组并支持查找；新会话继承最近选择的供应商、模型和档位，切回已有会话恢复该会话自己的选择。未选择时显示「选择模型」，不再提供「跟随主模型」。思考档位只展示该模型支持的选项，切到不支持当前档位的模型时回到模型默认；按钮样式沿用现有设计。

选择即时保存，只更新当前会话和新会话的继承默认，其它已有会话保持自身选择，应用重启后也分别恢复。保存成功后只回显发起选择的目标会话；期间禁用选择器与新消息提交，输入文字可继续编辑，也可切换阅读其它会话。失败保留原模型与草稿，使用已有错误提示和重试行为；迟到响应不改其它会话。当前生成和已受理队列继续使用受理时配置，历史中的模型与档位保持原记录。

设置 → AI 连接去掉「应用 / 已应用」、主模型用途条与标记，以及其他用途下拉。模型行提供单一「用于导入」按钮，沿用原来的主色样式；已绑定时显示禁用的次要样式「已用于导入」。顶部只展示导入模型及「恢复跟随」。未单独选择时显示「跟随 AI 助手」。供应商、模型编辑和测试连接沿用已有入口。

产品代码、设置与定位接口已落地，规格、版本清单及状态文档已同步。v0.8.1 未新增 schema，本轮 v0.8.2 修正使用 schema 20 保存独立模型版本与旧重试回执。工程验证不代替尚未执行的实机观感、DPI / 多显示器、读屏和真实供应商验收。
