# v0.8.1 AI 对话规格

> 2026-11-13，已按用户确认的 [UI/UX](ui-ux.md) 实现并通过工程验证。预览保留轮次与时间，整卡点击定位，错误直接显示一次；验证与未验收范围见[计划](plan.md)。

## 失败重连

全局运行设置增加 `retry`：`httpRetries=4`、`streamRetries=5`、`networkPersistent=true`、`networkRetries=5`。有限次数为 0–100 整数，0 禁用对应层级。旧持久化 JSON 缺少该对象时补默认值；旧客户端保存时没有提交 `retry`，保留已保存的重试配置。原预算不变，数据继续进入 APP_ROOT 内的便携数据库，保存从下一轮生效；沿用 schema 18。

上游返回结构化失败分类、实际状态码、错误代码、安全错误正文、收到错误时建立的等待截止时间及已收到的部分响应。网络无法建立连接使用独立等待分支；临时请求错误与流中断分别计数。鉴权、额度、参数与路径等不可恢复错误不重试。合法供应商等待建议优先，普通请求和流式恢复从 400ms 起按指数退避，有约 ±10% 抖动（首轮约 `[360, 440)` ms），断网等待为 5/10/20/40/60 秒后保持 60 秒；数值基线以 [功能清单](../../state/v0.8.1-features.md) 为准。

自动恢复留在原 `requestId`、原模型和工具上下文内；等待、重发及工具执行共用原整轮预算。每次实际外发单独结算用量，不生成额外数据库用户消息。不知道 usage 时不造计费数字；未开始生成的明确连接/HTTP 拒绝不扣生成预算。重试次数在真正开始恢复请求后增加，等待时只显示已发生次数。等待能立即停止，成功后清除临时恢复反馈。

Chat Completions 与 Anthropic Messages 没有原流续传协议。收到部分文本后将其保留为本轮前缀，带已有工具结果向同一模型请求继续回答；思考文本不当作用户指令或未签名的 Anthropic thinking block 重放。不执行未取得完整终态的工具调用，不重新执行已确认的工具步骤，不把这种继续请求描述成供应商原流续传。上下文/输出预算不足时保留部分结果并停止。

`metadata`、done / error、轮次与运行快照及历史消息增加 `recovery`：`kind`（request/stream/network）、`state`（waiting/connecting/failed/stopped）、`attempt`、适用的 `limit`（持续等待为 null）、`error`、可选 `nextRetryAt`（Unix 毫秒截止时刻）。前端仅在原回答处显示状态、一次安全报错及真实剩余等待；失败或停止的事实按原消息元数据加密保存，零正文也保存空助手消息以保留原因。成功清除临时状态，不常驻横幅。恢复期间会话保持 RUNNING，原停止和队列行为继续生效；各恢复计数在取得完整模型步骤响应后重置，整轮预算不重置。

## 会话内跳转

正文右侧放一个纵向定位控件，以当前保留的每条用户提问为轮次边界。自动恢复和同轮插话不新增提问，手动重新生成沿用现有追加新问答行为。刻度中心间距固定 10px，上下各留 8px，整组按数量收缩并垂直居中；13 轮高 136px，64 轮高 646px。容量基于父消息区高度扣除 64px 后的可用空间，上限由 64 个固定间距刻度计算为 646px。最多展示 64 个连续逐轮刻度，矮窗口减少数量而保持间距；超过上限在刻度或预览卡片上滚轮翻阅，阻止正文滚动，不自动定位。静止刻度短而淡，悬停 / 聚焦时所选与邻近刻度平滑变长，离开收回，减少动态效果时禁用过渡。

整体只有一个键盘定位停靠点；上下/Home/End 选择完整会话序列，Enter/Space 定位，Escape 关闭预览，卡片整体可点击。鼠标点击刻度直接定位且不强制聚焦，整条焦点边框只在键盘操作时出现。预览顶行显示轮次和提交时间，提问粗体最多 2 行，回答浅色最多 3 行；按排版截断并追加 `...`，不加提问 / 回答标签、状态栏或重复按钮。预览取已有文本片段，不调用模型。

时间取该轮用户消息的真实 `createdAt`，已加载消息、定位接口预览和会话列表共用解析规则：数据库无时区的 `YYYY-MM-DD HH:mm:ss` 及无时区 ISO 时间按 UTC 解析，带 `Z` 或明确偏移的 ISO 时间保留原时刻，再按系统时区显示。缺失或不可解析时不显示时间，不补当前时刻；预览 `<time>` 的 `datetime` 使用规范化的 UTC ISO 字符串。

首次指针移入等待 150ms，移动不重置等待；打开后通过 requestAnimationFrame 每帧最多处理一个最新目标，同轮已加载或正在加载时不重复预览请求。离开、跳转、触屏选择和卸载时取消待执行的计时器与动画帧。保留请求身份校验，只显示目标匹配的片段，加载中点击仍定位当前目标。文本节点保持挂载；长文本测量从最多 128 码点的短前缀开始，截断结果按原文及布局条件复用，单个导航最多缓存 128 个片段。缓存只用于文本截断，回答原文变化时重新计算。

历史分页增加 `totalRounds` 和页内首个提问的 `firstRound`；按 `afterMessageId` 正向加载时额外返回 `hasOlder`。页大小最多 50 条。`GET /api/ai/sessions/{id}/navigation/{roundNumber}` 返回目标提问 ID、总轮数、时刻、状态、historyRevision 及有界提问 / 回答片段（最多 240 / 600 码点）。目标超出最近 500 条时按目标消息 ID 加载有界阅读窗口，仍最多驻留 500 条，不全量读取正文。回到最新恢复最新分页。历史清理或会话切换使目标失效时提示读取失败，迟到请求不会跳到新会话。

跳转仅滚动正文，提问对齐顶部约 24px 并短暂标记，不修改草稿、附件、生成和队列状态。用户离开底部后不随输出、定稿或迟到分页强拉滚动；右下沿用回到最新。空 / 单轮隐藏刻度，窄窗与详情覆盖协调，文字复制 / 引用浮层期间隐藏导航，卡片不遮挡输入区。

## 助手模型选择

对话模型与思考档位为全局选择，从 `GET /api/ai/connections` 的 `chatModelId/chatReasoningEffort` 读取。`PUT /api/ai/connections/chat-model` 接受 `{revision, modelConfigId, reasoningEffort}`，成功返回新集合；模型须存在且连接与容量完整，显式档位须属于目标模型支持的 effort。只换模型而原档位不适用时回到模型默认，null 档位使用模型参数中的默认值。选择与已开启的记忆授权沿用现有事务同步，写入失败全部回滚。

全局选择保存在 APP_ROOT 内 `data/study.db` 的 `ai_connections.document`，旧 JSON 缺档位视为 null，schema 保持 18。供应商 / 模型编辑、导入绑定及能力回写均保留此选择；移除已选档位支持时清除该覆盖值。助手草稿兼容原格式，但其 choice 不在恢复时覆盖数据库；旧会话的 model_config_id/reasoning_effort 同样不再参与请求配置。

新建和更新会话不再接受独立的 modelConfigId/reasoningEffort，只修改会话元数据。所有新提交都冻结助手当时的全局配置；已有轮次、已受理队列、断流恢复与工具结果不随之后改选变化。历史模型和用量取真实记录。

设置里的 `/api/ai/connections/bindings` 只接受 `purpose:import`，modelId 为 null 时恢复跟随助手。设置不再有主模型应用入口；输入区选择器只列实际模型，不增加「跟随主模型」选项。保存期间禁用模型选择和新消息提交，草稿可继续编辑；失败保留旧选择，刷新配置后可重试。

## 验证门禁

覆盖三类退避、0 禁用、真实计数、服务端等待、不可恢复错误、停止/超时、部分输出和完整工具结果保留、使用量结算、设置旧数据兼容；导航覆盖跨分页、500 条上限、键盘、卡片直接定位、会话切换与迟到请求。模型选择覆盖跨会话、新会话、数据库重开、失败 / 冲突、导入独立、档位回退和已受理配置冻结。通过针对性测试、前后端构建与相关回归后更新状态文档；涉及设置持久化复跑便携审计。产品发布版本与工作流不在本切片中调整。
