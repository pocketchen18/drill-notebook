## 验收范围

- 无配置默认路径；Exa 失败后 Tavily 有界备用、真实业务错误与冷却。
- 自定义供应商的两类能力、共享密钥与独立选择、认证错误不替换服务。
- 本地静态正文、重定向与 DNS 重绑定、禁止私网 / 元数据、响应大小 / 解压上限、停止与总时间。
- 原生能力判定、只发送必要输入、来源解析、单次工具限制及用量 / 预算结算。
- 普通 / SSE 完整工具循环、执行前关闭权限、活动元数据与历史不包含网页正文或查询。
- 地球按钮的全开 / 全关 / 部分开启、原子保存、失败 / 冲突、跨窗口刷新；服务草稿保存 / 取消与权限隔离。
- 凭证只加密落在便携数据库、当前页面排除密钥与密钥草稿；新增依赖不产生外部运行时。
