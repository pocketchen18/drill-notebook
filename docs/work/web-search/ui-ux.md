# 联网搜索工具接入：UI/UX

> v0.8.2 F02，2026-11-14 已实现并通过工程验证。本文件记录已确认的工具设置与助手搜索入口；路由和服务依据见[需求](requirements.md)，具体能力见[规格](spec.md)，结果与实机验证边界见 [QA](qa.md)。

## 1. 入口与界面范围

- 主窗口沿用现有顶部设置分类，在「设置 → 工具」增加联网分组，置于现有学习资料等工具分组之前。保留当前行式工具开关，不新增设置侧栏或第二套工具管理页。
- AI 助手沿用既有会话栏、消息流与输入框。在输入框底部的模型选择、附件和发送工具栏中，附件旁增加一个地球按钮；不另加常驻「联网搜索」文字按钮、服务下拉框或重复开关。
- 服务配置集中在工具页；助手只显示当前开启状态和所选模式。运行时的实际服务、读取结果与错误使用现有工具活动，不新增平行状态面板。

## 2. 工具设置

联网分组默认如下：

| 项目 | 初始值 | 行为 |
|---|---|---|
| 联网搜索 | 开启 | 查找网页与来源；对应独立 search 权限，即点即存 |
| 网页读取 | 开启 | 读取指定公开 URL 正文；对应独立 fetch 权限，即点即存 |
| 优先使用模型内置 Web 工具 | 关闭 | 对实际支持的能力优先使用；不支持时使用已选服务，即点即存 |
| 搜索服务 | 内置自动（免配置） | 可选内置自动、Tavily、TinyFish，属于服务草稿 |
| 网页读取服务 | 内置自动（本地优先） | 可选内置自动、Tavily、TinyFish，属于服务草稿 |

权限行左侧是名称与一行说明，右侧是当前 Arco Switch。原生 Web 优先行说明「支持时优先使用；不支持时使用已选服务」，不在设置里增加主模型选择。

服务配置使用两列字段，窄窗口改为上下排列。每列只有服务选择及简短说明；内置自动不出现账号、密钥或连接地址输入。搜索说明「优先 Exa，受限时尝试 Tavily」；读取说明「优先本地正文提取，必要时使用内置服务」。服务内部路由不提供第二组供应商选项。

选择 Tavily / TinyFish 后，在字段下方按实际使用的供应商显示 API Key 配置。同一供应商同时负责 search / fetch 时共用一份密钥，只显示一个编辑区；选择两家时各显示一次。密钥默认遮挡，不在普通页面上下文、日志、工具活动或提示文字中回显。

### 保存与测试

- 权限和原生优先开关沿用现有即点即存语义，提交时短暂禁用，服务端确认后显示新值。开启从下一轮生效；关闭会阻止尚未执行的对应调用，不中断普通回答。正在执行的联网任务继续遵守现有停止机制。
- 服务选择与密钥构成独立草稿。有改动才出现「取消」「保存」，旁边保留「测试连接」。取消只还原服务草稿，不回滚已保存的权限开关，也不删除已有密钥。
- 保存前校验已使用的自定义供应商配置非空；保存失败保留草稿与具体安全报错。编辑已保存密钥时留空表示保留；删除使用明确动作并随服务草稿保存，不能由空输入意外触发。
- 测试使用当前服务草稿，可按搜索 / 读取能力分别给出结果，不能用 MCP 握手或 HTTP 200 代替有效工具返回。测试不自动保存、不改变权限；自定义服务尚未配置时先提示缺少字段。
- 恢复默认工具权限沿用现有工具页入口；不顺带删除供应商配置或密钥。版本冲突时重新读取当前设置，保留服务草稿，让用户再次选择；不自动覆盖其它窗口的修改。
- 服务配置和全局权限跨会话、重启保存，所有写盘沿用 APP_ROOT。关闭联网不清空服务配置，重新开启继续使用已保存的服务。

## 3. 助手地球按钮

地球按钮是全局 search / fetch 权限的快捷操作，两项仍能在工具页分别控制。它没有独立会话偏好，不存在设置已关闭但助手仍可联网的另一条路径。

| search / fetch | 按钮状态 | 提示 | 点击结果 |
|---|---|---|---|
| 开 / 开 | 强调色浅底，`aria-pressed=true` | 联网已开启 · 内置自动（或已选服务） | 原子保存两项关闭 |
| 关 / 关 | 普通附件按钮样式，`aria-pressed=false` | 联网已关闭 | 原子保存两项开启 |
| 开 / 关 | 部分开启，`aria-pressed=mixed` | 联网部分开启 · 仅搜索 | 原子保存两项开启 |
| 关 / 开 | 部分开启，`aria-pressed=mixed` | 联网部分开启 · 仅网页读取 | 原子保存两项开启 |
| 设置加载或保存中 | 暂不可操作 | 正在读取 / 保存联网设置 | 不提交重复操作 |

部分开启使用浅底与一枚小状态点区分，完整含义通过可访问名称和悬停 / 聚焦提示提供。状态来自同一份已保存权限；保存失败保留旧值并提示原因，多窗口更新后同步刷新。

提示反映所选模式，不能把「内置自动」始终写成「使用 Exa」，因为实际调用可能采用备用或本地读取。搜索与读取选择不同时，提示分别标注；已开启原生优先时补充「模型内置优先」，当前模型不支持则明确显示所选外部模式。具体能力以[协议支持矩阵](spec.md#原生联网支持矩阵)为准，不推测模型名称即可联网。

默认开启表示模型可以按需使用，不强制每轮执行搜索。模型暂不支持相应工具时说明能力限制，保留用户的全局偏好；不能以“模型内置优先”为由绕过已关闭的 search / fetch。

按钮使用当前附件按钮的尺寸、圆角与对齐，不改为独立大型胶囊。桌面可见图标约 16px，按钮约 32px；窄窗口工具栏按现有规则换行，地球与发送均保持可见。不在提示内增加「再开一次搜索」或供应商选择的重复操作。

## 4. 工具活动与错误

- 搜索活动显示「搜索网页 · 实际供应商」，完成后显示取得的来源数量；读取显示「读取网页 · 本地正文提取 / 实际供应商」及有效结果。结果带可引用的真实标题、URL 与片段，不伪造日期。
- 展开现有活动组可查看逐次调用。内置自动从 Exa 转向 Tavily 时在同一次工具活动中保留安全原因与实际路径，不新增一条重复搜索消息。
- 日额度不足、超时、匿名访问受限显示真实服务名与安全原因。已知冷却时间才显示剩余等待；未知恢复时间不虚构倒计时。全部不可用时说明结果不可用，不把失败改成「未找到内容」。
- 自定义服务的无效密钥 / 额度错误直接反馈，不静默改用另一家远程服务。已有的重新生成与停止入口足够，不为每种错误重复增加“展开报错”“再试一次”等按钮。
- 搜索失败不自动关闭工具权限，也不影响可用的已知 URL 读取。权限设置表达用户选择，服务可用性由活动反馈，不能混为同一种状态。

## 5. 视觉、键盘与上下文

沿用[设计系统](../../DESIGN.md)及[助手既有 UI/UX](../ai-conversation/ui-ux.md)。白 / 深色工作面、轻分隔线、6–8px 控件圆角和既有蓝色状态保持一致。只使用当前系统字体与 Lucide 图标，不引入新组件库、字体或图标网络依赖。

标签 13–14px，辅助说明 12px；字段遵循 4px 间距体系。联网分组不套多层卡片；自定义凭证按行组织，使用分隔线分组。弹出提示不遮挡发送或模型选择；草图在 320px–1024px 可重排。

按钮支持 Enter / Space，表单有对应标签，动态保存和测试结果使用现有消息反馈与可访问状态。提示同时支持悬停、键盘聚焦和触控；保持原生可见焦点，遵守减少动态效果偏好。桌面控制紧凑，触控有效目标约 44px。

「读取当前页面」对工具设置只暴露权限、已选服务和公开说明；密钥、草稿密钥及敏感连接字段不进入 AI 页面上下文。联网只发送必要查询 / URL，不自动把整段会话、笔记与记忆传给搜索服务。

## 6. 交互草图与设计核对

- [设置 → 工具](settings-preview.html)：可切换两项权限与原生优先，选择搜索 / 读取服务，展开对应凭证字段，演示保存、取消与连接测试。
- [AI 助手入口](assistant-preview.html)：可点击地球按钮开关联网、查看提示与展开现有工具活动；保留当前页面、上下文、模型、附件与发送的原布局。

草图使用虚拟内容，连接测试、保存和发送仅演示本地交互，不调用真实服务。凭证输入只供演示，不保存其内容；草图只记住非敏感的服务选择与开启状态。两份草图分别展示两个产品入口，不是两套互斥设计。

设计阶段两份草图通过 UTF-8、HTML 片段结构、脚本语法与 25 项离线 DOM 交互核对，草图没有调用真实服务。产品实现已通过地球按钮 8 项、服务配置 6 项及工具页 / 活动 / 助手相关回归；覆盖原子保存、全开 / 全关 / 部分开启、旧配置不可读、旧 GET 防覆盖、冲突与草稿隔离、凭证去重和页面上下文不含密钥。后端真实匿名探测与便携审计也已通过，完整结果见 [QA](qa.md)。Electron 键盘、触控、明暗主题与窄宽布局实机核对尚未执行。
