# 学习资料读取工具

> v0.7.3；用户已授权实现全部读取工具。已按本文实现，自动化验证见 [规格记录](spec.md)。复用现有工具活动界面，不新增常驻上下文卡片；保留至下一版开始前归档。

- 用户直接提问当前页、某本笔记、知识点、题库或错题；模型自行选择查找与读取工具。
- 活动行分别显示“读取当前页面”“查找学习资料”“读取笔记”“读取知识点”“读取题库”“读取错题”，沿用执行中、完成、失败、耗时与折叠交互。
- 回复使用工具返回的资料名称与应用内位置引用。读取有分页时只表述实际读取范围；未找到、已删除、版本变化与无页面快照均如实说明。
- 普通发送不再预先向模型注入页面正文或笔记检索结果。页面快照只随请求交给本地后端，正文在 `read_current_page` 被调用后才提供给模型；用户手动附件保持原行为。
- 快照绑定该条消息。排队后切页不换目标；插话拥有自己的请求标识，模型可按标识读取，默认仍读取主消息的页面。
- 页面快照明确采集时间、未保存状态、选中内容和已截断状态；作答中只包含已显示题面。资料内容属于引用数据，不能授权工具写入。

验收以真实工具调用链路、前端请求 / 状态回归和后端数据读取为主。本切片不实现新增、修改、删除资料工具或“工具”设置页。
