# 助手窗口规格

## 切片 1：独立窗口 MVP

> 2026-11-11 已实现并完成自动化与隔离实机核对。按确认的 [UI/UX](ui-ux.md) 落地；本片没有后端、接口或数据库变更。

### 窗口

- 主进程维护唯一的助手窗口，入口为同一份前端加 `#/assistant`。默认 980 × 760，最小 420 × 520；首次出现在主窗口所在显示器右侧。
- 关闭助手窗口只隐藏，渲染进程保留，会话、草稿、阅读位置和后台任务不受影响；再次打开复用同一窗口并聚焦输入框。关闭后台节流，隐藏期间仍上报运行状态。
- 位置、尺寸与最大化保存在 `APP_ROOT/config/assistant-window.json`；记住的位置不在任何显示器内时回到默认位置。
- 关闭主窗口即退出，助手窗口随之关闭。存在正在回复的会话或待发消息时先弹系统确认框，取消则继续运行。启动时不自动打开助手。
- 回复数量减少且助手窗口不在前台时只闪烁任务栏按钮。

### 跨窗口通道

预加载脚本新增 `assistant`（打开、切换、收起、状态、提醒、聚焦主窗口）与 `bus`（发布、订阅）。主进程只转发下列类型，并且只发给另一个窗口；来源必须是受信入口页面。

| 类型 | 方向 | 用途 |
|---|---|---|
| `page-context` | 主 → 助手 | 主窗口当前业务页面；切页或被请求时发送 |
| `context-request` | 助手 → 主 | 打开或重新获得焦点时索取当前页面 |
| `navigate` | 助手 → 主 | 用户点击资料来源、页面标记或设置入口；主窗口只接受站内路径 |
| `tool-mutation` | 助手 → 主 | 已确认的资料写入，主窗口经同一套白名单校验后刷新缓存、丢弃被删笔记草稿 |
| `invalidate` | 双向 | 指定查询键失效（如「插入笔记」后的页面） |
| `assistant-activity` | 助手 → 主进程 | 正在回复与待发数量，仅接受来自助手窗口，用于入口徽标与退出确认 |

消息的页面快照仍在提交时由助手窗口从最近一次收到的页面上下文生成，绑定规则不变。浏览器调试环境退回 `BroadcastChannel`。

### 前端

- `main.tsx` 按入口 hash 选择 `App` 或 `AssistantApp`。主窗口不再挂载助手组件，由 `useAssistantBridge` 把「打开 / 关闭助手」转成窗口操作，并以窗口真实可见性更新入口状态。
- `AiAssistant` 去掉抽屉，改为会话栏、对话区、详情栏三栏；窄于 760px 时会话栏为浮层、详情栏占满，760–1179px 详情栏覆盖在右侧。
- `SessionNavigation` 增加停靠模式：常驻列表、新建、标题查找，底部放存储占用、清理与设置入口；对话区顶栏的「更多」打开同一份菜单。原弹出模式保留。
- 上下文检查器与会话引用预览增加嵌入形态，显示在详情栏；切换会话时关闭。
- 快捷提示移到空会话页；输入区增加页面标记。
- 新增可改绑的窗口快捷键作用域 `aiWindow`：新建会话、查找会话、展开 / 收起会话栏。全局「打开 / 关闭 AI 助手」在助手窗口内表示收起。
- 助手窗口通过本地存储事件跟随主窗口的主题与快捷键设置；重新获得焦点时刷新共享设置查询。

## 切片 2：会话模型与思考档位

> 2026-11-11 已实现并完成针对性自动化验证；真实供应商待验收。

- schema 17 → 18：`ai_chat_session` 增加 `model_config_id`、`reasoning_effort`（均可空，空表示跟随主模型 / 模型默认）；`ai_chat_turn` 增加 `model_label`、`reasoning_effort`，记录该轮实际使用的供应商 · 模型与档位。旧会话升级后继续跟随主模型。
- `POST /ai/sessions` 与 `PUT /ai/sessions/{id}` 接受可选的 `modelConfigId`、`reasoningEffort`，空字符串或 null 表示清除；会话视图返回这两个字段。模型必须存在；档位必须是目标模型声明支持的 effort，否则 400。只换模型而旧档位不再适用时自动回到模型默认。新建会话时选择无效则不创建会话。
- 发送时按会话解析配置：选了模型就用它，否则用主模型；档位适用时覆盖该次请求的默认档位，不适用时使用模型默认。会话选择的模型已被删除、缺密钥或缺容量时明确报错，不换用其他模型。
- 配置在受理时冻结：直接发送、人工排队、工具派发都取目标会话当时的选择；已开始的轮次和已受理的待发消息不受之后改选影响。插话沿用目标轮次的配置。
- 历史分页为助手消息返回 `model`、`reasoningEffort`（有记录时），不随之后的改选变化。
- 前端 `ModelPicker` 位于输入区工具条：可查找的模型面板（首项「跟随主模型」、按供应商分组、能力标签、缺容量置灰、管理入口在主窗口打开 AI 连接）与档位菜单（只列该模型支持的档位，模型不支持调档时不显示）。新会话页的选择保存在本地，随首条消息创建会话时提交。回复顶部显示该轮实际使用的模型与档位。
- 预算型思考模型本片不提供会话内切换，沿用模型设置。

结果见 [QA 模块二十五](../../test/QA_CHECKLIST.md#模块二十五会话模型与思考档位v08)。

## 切片 3：上下文反馈

> 2026-11-11 已实现并完成针对性自动化验证；真实供应商待验收。

- `ai_chat_turn` 增加 `context_tokens`、`context_window`（同属 schema 18）：每次模型请求返回后，如果供应商回报了输入用量，就记下这次请求实际送入的 token 数（含缓存命中与写入部分）和当时的模型窗口。一轮内多次请求时保留最近一次，不累加；供应商未回报时保持为空，不写估算。
- `GET /ai/sessions/{id}/context-usage` 只读，返回 `{sessionId, latest, model, contextWindow, outputReserve}`。`latest` 是当前上下文代数里最近一次有实测值的请求 `{requestId, inputTokens, contextWindow, model}`，没有则为 null；后三项按会话当前所选模型给出，模型不可用时为 null。不发起模型请求，不读取消息正文。
- 历史分页为助手消息返回 `usage:{requests,inputTokens,outputTokens}`：该轮各次请求中供应商回报值的累计。未回报的轮次没有此字段。
- 前端 `ContextMeter` 位于输入区工具条：圆环与百分比表示最近一次请求占当前模型窗口的比例；没有实测值时退而使用最近一轮上下文计划的本地估算并标明「估算」；都没有时显示占位。新会话页和模型不可用时不显示。
- 说明面板：来源与数字、当前模型窗口及输出预留；改选模型后提示该请求发出时的窗口；打开面板时才读取该轮已保存的上下文账本，按「历史对话与摘要 / 本条提问与附件 / 记忆 / 系统提示」给出发送前的分项估算，实测值高于分项合计的部分列为「工具定义、工具结果及估算误差」。有摘要、有因容量省略的内容、占用超过 80% 时分别说明。底部可打开详情栏的本轮上下文。
- 回复操作行右端显示该轮累计实测用量，多次请求时在提示里说明是累计值。

结果见 [QA 模块二十六](../../test/QA_CHECKLIST.md#模块二十六上下文反馈与体验完善v08)。

## 切片 4：会话与消息体验

> 2026-11-11 已实现并完成针对性自动化验证；实机表现待验收。

- 会话栏在停靠模式下按最近活动分为「今天 / 近 7 天 / 更早」，组内保持原有顺序；查找时只显示有命中的分组。
- `ai_chat_turn` 增加 `page_title`、`page_link`（同属 schema 18）：轮次开始时记录提交时绑定的业务页面标题（最多 80 码点）与本地资料链接；没有业务页面时不记录，正文不保存。历史分页为用户消息返回 `page:{title,link?}`，界面在提问下方显示，点击在主窗口定位。
- 消息流上翻超过约 160px 时出现「回到最新」，其间有新内容到达则带提示点；点击回到底部并恢复跟随。
- 回复操作行新增「复制」；操作行在悬停或键盘聚焦到该回复时出现，最后一条回复和触控设备上始终显示。
- 未做：排队 / 插话区域的视觉重排（沿用现有贴边队列）、会话标题双击重命名（仍通过菜单或 F2）、新增窗口快捷键之外的键位。

## 验收修订（2026-11-11）

> 用户验收四个切片后提出，已实现并完成自动化与实机核对。

- **入口切换**：主窗口入口按钮与全局快捷键调用 `assistant:toggle`，由主进程按窗口真实状态决定。助手可见、未最小化并且持有焦点时收起；其余情况（未创建、已收起、最小化、被其他窗口盖住）打开并切到前台。点击主窗口的按钮会先让助手失去焦点，所以失焦后 700ms 内仍按「在前台」处理。业务页的定向入口（如「AI 分析错题」）仍然只打开，不会收起。
- **面板宽度**：`PanelResizer` 挂在会话栏与详情栏内侧边缘，支持拖动、方向键与双击重置。宽度写入助手窗口的本地存储（`ai.window.sideWidth`、`ai.window.detailWidth`），无效值回到默认；实际宽度另受 CSS 的窗口比例上限约束。
- **会话置顶**：`ai_chat_session` 增加 `pinned_at`（同属 schema 18）。`PUT /ai/sessions/{id}` 接受布尔 `pinned`，会话视图返回 `pinnedAt`。重复置顶保留最初的时刻；置顶不更新 `updated_at`。排序与分组在前端完成：置顶的按 `pinnedAt` 升序排在最前并归入「置顶」分组。
- **删除窗口保持在最前**（已被第二轮推翻，见下节）：当时把顶栏开关、`assistant:set-pinned` 接口、状态里的 `pinned` 字段与偏好文件里的对应项全部移除。

结果见 [QA 模块二十七](../../test/QA_CHECKLIST.md#模块二十七验收修订v08)。

## 验收修订（2026-11-11 第二轮）

> 用户第二轮验收提出「一边看回答一边记笔记」的用法，据此恢复窗口固定，并补三处交互细节。

- **窗口固定**：`assistant:set-fixed` 开关窗口的 `alwaysOnTop`，状态并入助手窗口状态（`fixed`）广播给两个窗口，并写进 `APP_ROOT/config/assistant-window.json`；重建窗口时按偏好恢复。只接受布尔值，非布尔按取消处理。固定期间点主窗口入口仍是收起（它不会在后台）。顶栏左侧与 ☰ 同组，用垂直图钉；会话置顶改用倾斜图钉，位置与角度都不重叠。
- **标题双击改名**：顶栏标题单击延后一拍展开会话栏，双击进入就地改名（输入框默认全选）。Enter 或失焦保存，Esc 取消；空白或与原名相同不发请求。改名走已有的 `PUT /ai/sessions/{id}`。
- **选中文本浮层**：消息流里选中文字后在选区上方浮出「复制 / 引用」（贴近顶部时放到下方）。引用把选区转成引用块（逐行加「> 」）追加到输入框并聚焦；浮层按钮用 mousedown 阻止默认行为，避免点按钮丢掉选区。点击别处、滚动、Esc、选区清空都会收起。
- **上下文面板只说输入与输出**：`ai_chat_turn` 增加 `cache_read_tokens` 与 `output_tokens`（同属 schema 18 的补列），`GET /ai/sessions/{id}/context-usage` 的 `latest` 一并返回。面板按「输入（缓存命中 / 未命中）+ 输出 + 窗口占比」展示，分项估算、摘要与裁剪明细归入「查看本轮上下文」。
- **面板分隔条拖动收尾**：拖动过程中的 pointermove/pointerup 改挂到 window，抬手坐标决定最终宽度并同步界面，修掉快速拖动时「最后一次移动丢失」的问题。

结果见 [QA 模块二十八](../../test/QA_CHECKLIST.md#模块二十八第二轮验收修订v08)。

## 验收修订（2026-11-11 第三轮）

- 回复操作行移除「本轮上下文」，改为圆形箭头「重新生成」图标按钮；常规设置移除「打开 AI 助手」。
- 重新生成先通过 `GET /ai/turns/{requestId}/input` 只读取原提问和完整附件，再用新 requestId 和 `retryOf` 走既有 v2 聊天入口。已清理、未解锁、损坏或仍在运行的原轮次不可重发；附件缺失时整次拒绝，不悄悄丢附件。
- 使用当前会话的模型和主窗口当前页面；新轮次追加到末尾，保留原回答和输入草稿。准备期间阻止重复点击与其他发送，切会话取消尚未发送的准备；原输入不写浏览器存储。已有写入工具沿用 retryOf 链的回执。
- 上下文明细仍由上下文占用面板或记忆徽标进入；上下文占用浮层不读取分项审计，模型名不带供应商、不重复展示窗口与输出预留。会话菜单的置顶图标与会话行一致，使用倾斜图钉。

结果见 [QA 模块二十九](../../test/QA_CHECKLIST.md#模块二十九重新生成与入口精简v08)。
