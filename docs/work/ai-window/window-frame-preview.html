这页用差商的极限定义了导数。可导意味着下面这个极限存在且有限：

f′(x₀) = limh→0 [ f(x₀ + h) − f(x₀) ] / h

把分子改写成 差商 × h：当 h→0 时差商趋于有限数 f′(x₀)，h 趋于 0，乘积也趋于 0，所以 f(x₀+h) → f(x₀)，这正是连续的定义。反过来不成立，页面里 |x| 在 0 处的例子就是连续但不可导。
