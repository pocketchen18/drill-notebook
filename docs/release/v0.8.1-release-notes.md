# Drill Notebook v0.8.1 预发行说明

- 版本：`v0.8.1`（Pre-release）。
- 准备日期：2026-11-13。
- 发行产物：`Drill-Notebook-0.8.1-win-x64-portable.zip` 及对应 `.zip.sha256`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文记录发布准备，实际发布时间及下载附件以对应标签的 [GitHub Release](https://github.com/qilin-software/drill-notebook/releases) 为准。

## 主要变化

- **失败自动重连**：可恢复的请求失败、限流和回答中断会自动重试。原回答处显示实际次数、供应商具体报错和等待时间，期间可随时停止。在「设置 → AI 对话 → 运行限制」自定义上限。请求默认重试 4 次，回答默认重连 5 次，设为 0 可关闭对应自动重试。
- **重连策略与回答保留**：请求重试与回答重连从 400ms 起逐步延长等待，服务端指定等待时间时优先遵守；纯断网默认持续等待，也可设置次数上限。恢复保留部分回答、已确认的工具结果和原轮次配置，继续使用原运行预算。
- **会话内对话跳转**：聊天正文右侧新增刻度导航，最多同时显示 64 轮，更多轮次可通过滚轮翻阅。悬停预览轮次、时间、粗体提问和浅色回答；提问最多两行、回答最多三行，超限显示 `...`。点击刻度或整张卡片即可定位，也支持键盘与跨页历史，跳转保留草稿、附件和正在生成的内容。
- **助手模型选择持久化**：对话模型和思考档位统一在 AI 助手输入区选择，保存后跨会话、新会话和重启保留。设置里的模型用途只保留「用于导入」，导入模型可独立选择，未单独设置时跟随助手。已受理的轮次、队列与自动重连继续使用提交时的配置。
- **导航时间与悬停修正**：预览使用该轮真实提问时间，并按系统时区显示，修正数据库 UTC 时间被当成本地时间的问题。刻度固定间距并整组居中，悬停更新更流畅，鼠标点击不会留下整条蓝色焦点边框。
- **当前页面适配修复**：AI 助手可以读取设置当前分区的选项与状态，包括「关于」的实际版本和更新检查结果；也能读取日历的当前月份、选中日期、计划与合并学习队列。页面变化同步更新，已发送消息仍绑定原快照；设置中的密钥和密码不会进入页面正文。

## 升级与数据

1. v0.8.0 可在「设置 → 关于」检查更新，或使用已开启的自动更新。手动升级时先退出旧版并备份完整便携目录，再替换程序；保留 `data/`、`config/`、模型、附件和 `backups/`。
2. 本版沿用 **schema 18**，不新增数据库迁移。重试设置和助手模型选择保存在现有便携数据库中，已有学习资料、会话、记忆、模型配置与工具偏好继续保留。
3. 升级后保留原全局对话模型作为助手初始选择；之后使用助手最近成功保存的模型与思考档位，旧会话或草稿不会覆盖它。已有独立导入模型绑定继续保留。
4. 自动重试不会重置整轮运行预算，各次实际上游请求分别记录使用量。停止、达到重试上限或遇到不可恢复错误时，保留已有回答和具体原因，可沿用「重新生成」主动重试。
