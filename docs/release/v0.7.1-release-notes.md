# Drill Notebook v0.7.1 预发行说明

- 版本：`v0.7.1`（Pre-release）
- 准备日期：2026-11-08
- 发行产物：`Drill-Notebook-0.7.1-win-x64-portable.zip`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文用于发布准备；是否已发布、最终提交与附件以 GitHub 对应标签的 Actions / Release 为准。

## 主要变化

- **多供应商与多模型配置**：设置中的「AI 连接」改为供应商与模型列表；连接、模型参数使用独立二级页。可将指定模型应用为主模型，导入模型可独立选择或跟随主模型；保存参数与应用模型分开。
- **模型预设与思考档位**：内置参考预设，支持搜索、点击或回车填入；模型 ID 可编辑。修改 ID 保留已设置的参数和未保存草稿，只有明确选择其他预设才覆盖对应字段。支持配置思考档位、默认档位及适配协议的思考预算；不包含 `ultra`。
- **自动发现与验证**：新增供应商自动获取一次模型列表；选中后以最多 3 个模型并发验证。文本请求决定能否添加，图片与工具验证分别记录，工具验证成功自动开启工具调用；失败可重试，全部请求可取消。
- **对话内记忆工具**：模型可按需检索、列出、新增和更新记忆。工具遵循会话作用域、精确值去重和版本检查；用户明确要求重新记住时可恢复此前删除主题的记忆。
- **工具活动可见**：助手回复内显示工具名称、开始时间、耗时与实际结果；支持展开详情、折叠与历史恢复。已确认写入不会因取消或断连被误报为未执行；不展示原始工具参数或记忆正文。
- **全局运行限制**：「设置 → AI 对话 → 运行限制」可修改和恢复默认，切换模型不变。默认每轮 50 个工具阶段、100 次工具执行、整轮 30 分钟、单次请求 15 分钟；Token 额度及重复调用停止阈值也可配置，保存从下一轮生效。
- **长轮次与收尾**：放宽旧的记忆条数与写入次数总限制；达限保留已有结果、显示原因并提供「继续」。长连接增加心跳，等待响应头时也可取消，断流保留已收到正文。
- **稳定性修复**：流式生成时可自由向上阅读；切换聊天模型不再无故反复重建同版本记忆索引；删除来源会话或清理历史保留已保存的长期记忆，来源显示「来源已被删除」，不改成「人工添加」。

## 升级与数据

1. 退出旧版本，备份完整便携目录，保留 `data/`、附件及 `backups/`。
2. 新版本使用 **schema 11**：schema 10 增加供应商/模型集合，schema 11 增加全局运行限制；启动迁移前自动在 `APP_ROOT/backups/` 创建数据库快照，快照失败则停止迁移。
3. 首次读取 AI 连接时迁移原有主模型与导入模型，保留加密密钥及原参数；未配置独立导入模型时沿用主模型。
4. 升级后的数据库不要直接交给旧程序打开；需要回退时使用升级前完整备份。所有运行数据继续位于便携目录。

## 已知边界

- 本版延续预发行渠道。v0.7.0 完整 120 例 §7 评测缺口没有在本版重新补齐，不将此前 PARTIAL 场景改写为 PASS。
- 新增连接与工具链主要通过本机 HTTP 回环和隔离浏览器验证；不代表所有真实供应商、预设参数及思考档位均已逐一联网验证。200% 缩放和读屏软件验收仍未完成。
- 记忆检索使用当前内存词法索引；向量语义记忆检索和独立用量详情页面未在本版交付。`list_memories` 单次最多 20 个标题，尚无分页 cursor。
- 全局运行预算仍受模型输入/输出容量约束；供应商未报告 usage 时，只在执行预算中按分配额度保守扣减，不伪造实际用量。「继续」创建新一轮，沿用已有会话回答，不恢复原上游连接或原始工具结果。
- v0.8 对话侧栏改版、系统提示词配置、联网搜索及自动压缩设置仍处于后续讨论范围。

## 发布方式

发布者先完成待发布提交的本地前后端全量测试，再推送 `v0.7.1` 标签。GitHub Actions 执行发布配置检查、前端类型检查、前端/Electron 与后端构建及 Windows 便携打包，再创建 Pre-release；云端不重复执行前后端业务全量测试，后端使用 `-DskipTests package`。Release 正文载入本文件并附自动生成的提交说明。手动触发默认 `v0.7.1`，默认仅上传构建产物，勾选 `publish_release` 才发布。

工作流按完整基础版本选择 `docs/release/<tag>-release-notes.md`，`v0.7.1-rc.1` 共用本文件；缺失或空白的发布说明会在安装依赖前阻止构建。包内版本由标签注入，工程内部 `0.1.0` 及后端 JAR 文件名不作为发行版本。

全局功能清单见 `docs/features.md`，状态文档和施工归档分别见 `docs/state/api-contracts.md`、`docs/state/data-model.md` 和 `docs/archive/v0.7.1/`。本地不生成发行包；实际云端构建与解压启动验收须在标签发布流程完成后核对。
