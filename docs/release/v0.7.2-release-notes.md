# Drill Notebook v0.7.2 预发行说明

- 版本：`v0.7.2`（Pre-release）
- 准备日期：2026-11-09
- 发行产物：`Drill-Notebook-0.7.2-win-x64-portable.zip`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文用于发布准备，构建结果和下载附件以对应标签的 GitHub Actions / Release 为准。

## 主要变化

- **AI 会话标题**：根据首个完整问答异步生成简短标题，不阻塞聊天；失败保留临时标题，可从菜单重试。人工重命名优先，迟到的自动结果不会覆盖人工标题，旧会话不批量改名。
- **会话列表与菜单**：支持右键及更多菜单中的复制链接、复制或导出内容、重命名和删除等操作。点击新建、删除当前会话后均回到未保存的新会话页，首条有效消息发送时才创建会话。
- **跨会话查阅**：新增 `list_sessions` 与 `read_session`，AI 可以根据当前问题发现历史会话，或按粘贴的会话链接读取记录。支持筛选、分页、候选消歧和长会话分段读取；回复中的会话来源可打开预览。
- **跨会话派发**：新增 `create_session` 与 `send_message`。用户委派后，AI 可携首条消息创建普通会话，或向已有会话发送消息；忙碌目标按顺序接续。AI 创建的会话与人工会话相同，可以正常进入、继续聊天。
- **多会话并行**：会话列表显示各会话独立的运行圆环、待发送和异常状态，支持分别停止。切换会话不停止后台任务，本次前端运行中的输入草稿、附件和阅读位置按会话保留。
- **人工消息排队**：模型回复期间仍可输入并发送，待发消息贴在输入区上方，按顺序各自开启下一轮。支持展开、编辑、移除与撤销、暂停与继续；编辑队列项不覆盖输入框中的另一份草稿。
- **插话而不中断**：输入区及待发项可选择「插话」，提示为「提交，但不中断模型运行」。补充在下一次模型请求前接入当前轮次，不中止正在输出的内容或工具；已接收插话会出现在历史、后续上下文、跨会话读取及 Markdown / HTML / JSON 导出中。
- **停止与恢复**：停止或失败后保留尚未开始的人工消息并暂停，工具派发的待发项取消。人工待发内容加密保存，后台重启后恢复为暂停状态；已经开始或交付结果未知的内容不会自动重发。

## 升级与数据

1. 退出旧版本，备份完整便携目录，保留 `data/`、附件和 `backups/`，再替换应用程序。
2. 本版使用 **schema 14**。相较 v0.7.1 的 schema 11，新增稳定会话引用与标题元数据、派发收据及运行记录、人工待发内容与队列暂停状态。旧会话保留标题与历史。
3. 启动迁移前自动在 `APP_ROOT/backups/` 创建数据库快照；快照失败会停止迁移。待发正文与附件请求体在现有本地数据库中加密保存，不增加系统目录或协议注册。
4. 重启不会自动恢复模型运行。人工待发内容需确认后继续；模型配置已失效时保留内容并提示处理。尚未发送的输入框草稿不等同于已经受理的持久化队列。
5. 升级后的数据库不要交给旧程序打开；如需回退，使用升级前完整备份。
