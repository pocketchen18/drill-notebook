# Drill Notebook v0.7.0 预发行说明

- 版本：`v0.7.0`（Pre-release）
- 日期：2026-11-05
- 基线提交：`d407675`
- 发行渠道：GitHub Pre-release；不是正式稳定版

## 主要变化

- **AI 跨会话记忆**：GLOBAL / NOTEBOOK scope；关键词意图兜底；自动提取直接写入；精确值去重；人工保护不被自动覆盖。
- **记忆管理**：平铺卡片、内容派生标题、会话来源、有效期编辑、启停、单条删除；不在 UI 暴露版本号和内部谓词。
- **用量与缓存**：OpenAI cached 子集不重复计费；Anthropic cache read/write 分桶；SSE usage 合并；官方 Anthropic 尝试 `cache_control`，缓存字段 400 最多单次降级并持久化。
- **删除与恢复**：会话运行中删除返回 409；notebook 删除清理 NOTEBOOK scope；恢复前安全备份、staged DB 校验、恢复后安全事务和 fail-closed。
- **稳定性**：SSE CRLF/UTF-8/多行 data 边界、会话终态恢复、状态接口回读已落库 reply/reasoning、V1 摘要拒用。

- **附件**：维护 payload 不发送附件正文；旧混合附件消息不自动学习。

## 升级与备份

1. 先退出正在运行的旧版本。
2. 备份整个便携目录，至少保留 `data/study.db` 和 `backups/`。
3. 解压新版本到新的便携目录后启动；恢复功能在换库前会自动创建安全备份。
4. 预发行版请勿直接覆盖唯一一份生产数据。
