# Drill Notebook v0.8.0 预发行说明

- 版本：`v0.8.0`（Pre-release）。
- 准备日期：2026-11-12。
- 发行产物：`Drill-Notebook-0.8.0-win-x64-portable.zip` 及对应 `.zip.sha256`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文记录发布准备，实际发布时间及下载附件以对应标签的 GitHub Actions / Release 为准。

## 主要变化

- **独立 AI 助手窗口**：助手与主业务窗口可以同时操作，支持移动、缩放、最大化和窗口固定。重复点击入口可唤回或收起助手；关闭助手保留后台任务，关闭主窗口退出整个应用。窗口位置、大小和当前会话可恢复，固定状态与会话置顶分别显示。
- **跨窗口协作**：从笔记、知识点、题库等业务页带着目标打开助手；当前页面仍绑定提交时的主窗口页面。资料来源回到主窗口定位，AI 修改资料后两个窗口同步刷新，会话、草稿和运行状态互不串用。
- **会话内选择模型与思考档位**：在对话中搜索已配置的供应商和模型，设置当前会话支持的 effort。新会话默认跟随全局主模型，已受理轮次和排队消息保留提交时的配置，历史记录实际使用的模型与档位。
- **会话与消息体验**：标题筛选、独立置顶分组、双击标题改名、会话与详情栏拖动调宽；选中文字可复制或引用。回复底部统一按钮样式，新增圆形箭头「重新生成」，保留原提问、附件、旧回答和当前草稿；「本轮上下文」入口移入输入区占用面板，常规设置移除重复的助手入口。
- **上下文与运行反馈**：输入区展示最近请求的上下文占用、模型容量、输入缓存命中 / 未命中和输出用量；缺少实际 usage 时保留未知或估算标识。长回复上翻不强制滚回底部，思考、工具活动、后台并行、排队与插话继续沿用已有状态和恢复语义。
- **关于与软件内更新**：新增当前版本、带图标的 GitHub 主页和 Star 入口；手动 / 周期检查更新，检查与启动提醒共用可设置间隔，默认 24 小时。发现新版后顶部入口常驻，已是最新版或跳过该版本时隐藏；关闭说明弹窗只关闭界面。
- **逐版更新内容**：检查更新只展示安装版之后的未安装版本；关于页独立入口提供 Magpie 式范围菜单，可查看上次更新以来、当前安装版及其之前指定数量的版本。每个版本保留自己的 GitHub Release 正文，不混合成一段说明。
- **一次操作更新与自动重启**：点击「立即更新」后显示进度，连续完成下载、校验、保存草稿、正常退出、替换和重启。独立的自动更新默认关闭，开启后每次启动立即检查并自动完成更新，不受周期检查间隔限制；运行中开启只保存后续启动偏好。
- **便携替换与失败恢复**：内置 Windows 更新助手，ZIP 与逐文件清单双重 SHA-256 校验。等待 Electron 和 JVM 正常退出后备份程序及停机数据库；新版启动失败恢复旧程序和数据并避免同一失败版本的自动更新循环。更新设置、缓存、暂存、草稿与备份均在 APP_ROOT。

## 升级与数据

1. v0.7.3 及更早版本需要手动升级：退出旧版，备份完整便携目录，再替换新版程序；保留原有 `data/`、`config/`、模型、附件和 `backups/`。本版的软件内更新能力用于后续升级。
2. 相较 v0.7.3 的 schema 17，本版升级至 **schema 18**，增加会话模型 / 思考档位、置顶、实际用量与提交页面引用等字段。迁移前创建数据库快照，快照失败会停止迁移；已有学习资料、会话、记忆和工具偏好继续保留。
3. 原有会话未设置专用模型时继续跟随主模型，未设置 effort 时使用模型默认；未上报的历史用量不会补造精确数字。
4. 更新会保存主窗口笔记与助手草稿，并受运行任务和保存状态保护。只有下载完成、校验通过并满足退出条件才替换程序。
5. 升级后的数据库不要交给旧程序打开；需要手动回退时恢复升级前完整备份。软件内失败恢复使用事务记录的旧程序和停机数据库基线。
