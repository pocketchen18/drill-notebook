# Drill Notebook v0.7.3 预发行说明

- 版本：`v0.7.3`（Pre-release），v1.0 之前均不保证稳定性。
- 准备日期：2026-11-10。
- 发行产物：`Drill-Notebook-0.7.3-win-x64-portable.zip`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文记录发布准备；实际构建、发布时间及下载附件以对应标签的 GitHub Actions / Release 为准。

## 主要变化

- **按需读取学习资料**：新增 `read_current_page`、`search_materials`、`read_notebook`、`read_knowledge`、`read_question_bank`、`read_wrong_questions`。AI 可根据问题查找并分段读取当前页面、笔记、知识点、题库或错题，回答附本地来源链接。当前页绑定消息提交时的页面，支持未保存笔记草稿；不是系统桌面截图，也不会读取其它应用。
- **新增与修改资料**：`create_material` 可新建笔记本、笔记页、知识点、题库、题目，或将题目人工加入错题本；`update_material` 修改明确目标的指定字段。保存后是普通业务资料，可由人工继续编辑。修改核对读取版本、保护未保存草稿，重试不重复创建或追加，人工加入错题不伪造作答统计。
- **删除与移出工具**：新增 `delete_memory`、`delete_session`、`delete_material`、`remove_wrong_question`。删除资料先读取并核对版本，非空笔记本 / 题库需要明确一并删除；当前、上游、运行或排队中的会话受到保护。移出错题本保留原题与作答记录，删除来源会话保留长期记忆。
- **全局工具设置**：「设置 → 工具」展示全部 20 个内置工具，按学习资料、记忆、会话、删除分组。16 个非删除工具默认开启，4 个删除工具默认关闭；各项独立保存、保留已有选择并可恢复默认。开启从下一轮生效，关闭拦截尚未执行的调用；模型工具能力与记忆授权仍需满足，派发任务不提供删除能力。
- **精简 AI 侧栏**：移除常驻「当前上下文」卡片与右下角悬浮入口，保留右上角按钮、快捷键和业务定向入口。新前端不再自动注入整页正文，改由工具按需读取；附件、排队与插话继续保留各自目标。独立 AI 窗口留待 v0.8。
- **模型容量必填**：上下文窗口与最大输出必须填写，取消独立「最大输入」和缺值时的保守窗口。模型 ID 编辑仍保留已有设置及未保存草稿，只有明确选择预设才覆盖对应字段。

## 升级与数据

1. 退出旧版本，备份完整便携目录，保留 `data/`、附件和 `backups/`，再替换应用程序。
2. 相较 v0.7.2 的 schema 14，本版升级至 **schema 17**：增加资料新增 / 修改 / 删除回执、人工加入错题的作答基线，以及全局工具设置。迁移前在 `APP_ROOT/backups/` 创建数据库快照；快照失败会停止迁移。已有资料、会话及记忆继续保留。
3. 旧模型若缺少上下文窗口或最大输出，会保留原配置但无法用于调用；请在「设置 → AI 连接」补齐容量，或明确选择匹配预设后保存。
4. 工具偏好保存在既有本地数据库，已保存的选择不会被升级覆盖。删除工具默认关闭；开启后仍只按当前用户的明确目标与范围操作。
5. 升级后的数据库不要交给旧程序打开；需要回退时使用升级前完整备份。联网搜索配置、移动工具、批量删除与删除恢复未在本版交付。

## 发布方式

推送 `v0.7.3` 标签后，工作流校验版本及本文件、安装锁定依赖、运行发布配置回归，再构建前端、Electron、Java 17 后端与内嵌 JRE，生成便携 ZIP 并创建 **Pre-release**，不标记为 Latest。云端不重复本地前后端业务全量测试；后端使用 `-DskipTests package`，保留编译检查。

手动触发默认 `v0.7.3`，默认只上传构建产物；勾选 `publish_release` 才发布。`v0.7.3-rc.1` 等后缀版本复用本说明。发行版本由工作流注入；工程内部 `0.1.0` 与固定后端 JAR 文件名不作为发行版本。
