## 1. 当前 MVP 核心闭环（已落地）

| 顺序 | 模块 | 能力 |
|---|---|---|
| 1 | 题库 | 题库 / 题目增删改查；Markdown、PDF、JSON 导入；内容哈希去重；导出 |
| 2 | 刷题 | 会话抽题、提交判分、进度与快捷键；错题记录；会话结束学习计划推荐 |
| 3 | 错题 | 按累计错误次数排序并附错误率；连续答对 2 次自动清出；手动移出后答错重新计入 |
| 4 | 背诵 | 背题 / 背知识点；会话内短周期曲线与多轮循环；顽固项加练；评分写入跨天 SM-2 |
| 5 | 复习与日历 | 复习方案、到期队列、今日队列、计划组；AI 排程失败时规则降级 |
| 6 | 笔记 | TipTap 编辑器、公式 / 图表 / 代码块、附件与视频、页内查找替换、自动保存、混合检索 |
| 7 | AI 助手 | 多会话、页面上下文、知识点总结、检索引用、密钥加密、本地后端代理 |
| 8 | 设置 | 主题、快捷键、界面状态记忆、主模型与导入兜底模型分轨 |
| 9 | 便携运行 | 数据 / 日志 / 缓存 / 临时目录落在 APP_ROOT；不依赖注册表 |

## 2. 当前规划（v0.7.1）

在 v0.7.0 记忆系统之上，让 AI 在对话中按需调用记忆工具：

- `list_memories`：按授权范围分批查看记忆标题。
- `search_memories`：按查询检索并读取相关记忆。
- `create_memory`：在用户表达长期保留意图时新增记忆。
- `update_memory`：在用户纠正或补充时更新对应记忆。
- 配套：工具编排与预算、权限与范围、操作状态展示、自然语言记忆管理、语义检索、用量统计。

完整需求：[work/v0.7.1-ai-memory-tools/requirements.md](work/v0.7.1-ai-memory-tools/requirements.md)。
施工文档：[work/v0.7.1-ai-memory-tools/](work/v0.7.1-ai-memory-tools/)。

## 3. 后续候选

- 知识图谱、完整考试模拟、多人协作。
- SQLCipher 整库加密、自然语言改写日期控件。
- 记忆工具之后的扩展：更细的授权策略、跨设备同步（未立项）。

## 4. Non-Goals（当前明确不做）

- 不重做 v0.7.0 已交付的记忆管理、自动整理与对话记忆预注入。
- 不兼容旧 v1 AI 客户端；v0.7.0 起使用 v2 协议。
- 不在本地执行正式发行打包；正式发行只在 GitHub Actions 上做。
- 不把未验证的 PARTIAL 场景写成 PASS，不用评测 harness 的局部结果冒充完整 §7。
