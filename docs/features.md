## 1. 当前 MVP 核心闭环（已落地）

| 顺序 | 模块 | 能力 |
|---|---|---|
| 1 | 题库 | 题库 / 题目增删改查；Markdown、PDF、JSON 导入；内容哈希去重；导出 |
| 2 | 刷题 | 会话抽题、提交判分、进度与快捷键；错题记录；会话结束学习计划推荐 |
| 3 | 错题 | 按累计错误次数排序并附错误率；连续答对 2 次自动清出；手动移出后答错重新计入 |
| 4 | 背诵 | 背题 / 背知识点；会话内短周期曲线与多轮循环；顽固项加练；评分写入跨天 SM-2 |

| 6 | 笔记 | TipTap 编辑器、公式 / 图表 / 代码块、附件与视频、页内查找替换、自动保存、混合检索 |
| 7 | AI 助手 | 多会话、页面上下文、知识点总结、检索引用、记忆工具调用（`search_memories` / `list_memories` / `create_memory` / `update_memory`）、密钥加密、本地后端代理 |
| 8 | 设置 | 主题、快捷键、界面状态记忆、主模型与导入兜底模型分轨 |
| 9 | 便携运行 | 数据 / 日志 / 缓存 / 临时目录落在 APP_ROOT；不依赖注册表 |

## 2. v0.7.1 记忆工具（进行中）

在 v0.7.0 记忆系统之上，让 AI 在对话中按需调用记忆工具：

| 能力 | 状态 |
|---|---|
| `search_memories`：按查询检索并读取相关记忆 | 已实现 |
| `list_memories`：按授权范围查看记忆标题 | 已实现 |
| `create_memory`：自然语言新增记忆（归一化去重、证据、作用域与有效期、被删除主题的显式重记） | 已实现 |
| `update_memory`：自然语言更新记忆（正文/ID 双定位、乐观锁、证据继承、不跨作用域） | 已实现 |
| 工具编排与预算、权限与范围、设置页「工具调用」开关 | 已实现 |
| 操作状态展示、语义检索、用量统计 | 待实现 |

- 工具开关位于「设置 → AI 连接 → 聊天模型卡片」；自定义或未验证端点默认关闭，需显式开启。
- 工具调用只对 v2 协议且本轮启用记忆的聊天生效；导入兜底模型不启用。
- 工具结果只进入本轮上下文，不写入会话历史、SSE 或日志。
- 自动提取对「请加入记忆 / 请记住 …」类消息只保存事实正文，剥离命令前缀；只有命令没有事实时不落库。
- 用户明确说「请记住」时，`create_memory` 会解除该主题之前删除留下的 `FAMILY` 抑制并重建索引；没有明确要求时返回 `SUPPRESSED`，不会写一条读路径看不见的幽灵记忆。`PREDICATE` / `EVIDENCE` 抑制仍留给自动提取。
- 纠正已有记忆时，如果 `search_memories` 没命中，模型会按 `list_memories` 标题里的主题词再检索一次，避免「我是女的」与存储的「用户是男性。」措辞不同就误判没有记忆。
- 单轮工具阶段 ≤2、执行 ≤3、上游请求 ≤3；记忆条目单轮合计 ≤15；单轮记忆写入（新增 + 更新）≤3。
- 当前验证：`MemoryUpdateToolTest` 14 项、`MemoryCreateToolTest` 14 项、`MemoryListToolTest` 9 项、`MemoryToolChatPathTest` 6 项定向测试通过；完整后端测试 1189 项通过 / 3 跳过；运行态新会话已用真实端点验证 `create_memory` 成功写入并推进 vault revision。`search_memories` 切片的后端定向测试与设置页开关浏览器验证已通过，前端测试 719 通过 / 4 跳过。`update_memory` 真实端点、正式发行打包、真实第三方端点兼容性矩阵待验证。

## 3. 后续候选

- 知识图谱、完整考试模拟、多人协作。
- SQLCipher 整库加密、自然语言改写日期控件。
- 记忆工具之后的扩展：更细的授权策略、跨设备同步（未立项）。

## 4. Non-Goals（当前明确不做）

- 不重做 v0.7.0 已交付的记忆管理、自动整理与对话记忆预注入。
- 不兼容旧 v1 AI 客户端；v0.7.0 起使用 v2 协议。
- 不在本地执行正式发行打包；正式发行只在 GitHub Actions 上做。
- 不把未验证的 PARTIAL 场景写成 PASS，不用评测 harness 的局部结果冒充完整 §7。
