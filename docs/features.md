| 顺序 | 模块 | 能力 |
|---|---|---|
| 1 | 题库 | 题库 / 题目增删改查；Markdown、PDF、JSON 导入；内容哈希去重；导出 |
| 2 | 刷题 | 会话抽题、提交判分、进度与快捷键；错题记录；会话结束学习计划推荐 |
| 3 | 错题 | 按累计错误次数排序并附错误率；连续答对 2 次自动清出；手动移出后答错重新计入 |

| 6 | 笔记 | TipTap 编辑器、公式 / 图表 / 代码块、附件与视频、页内查找替换、自动保存、混合检索 |

| 8 | 设置 | 主题、快捷键、界面状态记忆、主模型与导入兜底模型分轨 |
| 9 | 便携运行 | 数据 / 日志 / 缓存 / 临时目录落在 APP_ROOT；不依赖注册表 |

## 3. 下一迭代（v0.7.1）

### 3.1 AI 记忆工具（4 个）

| 工具 | 用途 | 状态 |
|---|---|---|
| `list_memories` | 按授权范围分批查看记忆标题 | 待实现 |
| `search_memories` | 按查询检索并读取相关记忆 | 已实现（工作树，待提交） |
| `create_memory` | 把对话中具有长期价值且用户希望保留的信息新增为记忆 | 待实现 |
| `update_memory` | 用户纠正或补充时更新对应记忆，避免新旧内容重复并存 | 待实现 |

### 3.2 配套能力

- AI 根据对话需要自主决定是否调用记忆工具，并在操作完成后继续回答。
- 记忆工具权限与范围控制：只能读取或维护当前会话已授权范围，不把无效或过期内容作为当前事实。
- 对话中展示记忆操作状态，以及哪些记忆内容参与了回答。
- 用户可用自然语言记录和维护长期记忆，不必理解内部类别。
- 语义记忆检索：换说法或同义表达也能召回相关记忆。

### 3.3 用量统计

- 按模型和时间范围查看 AI 输入、输出、缓存使用及节省情况。

当前施工文档：[work/v0.7.1-ai-memory-tools/](work/v0.7.1-ai-memory-tools/)。

- 不在本地执行正式发行打包；正式发行只在 GitHub Actions 上做。
- 不把未验证的 PARTIAL 场景写成 PASS，不用评测 harness 的局部结果冒充完整 §7。
