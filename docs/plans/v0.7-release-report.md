## 1. 用户在哪开启，后台会发什么给谁，一天最多花多少估算 Token？

- 开启位置：记忆设置页的“使用记忆”和“自动提取”开关；两者独立授权。AI 配置页决定维护调用使用的 endpoint/model。
- 外发对象：用户配置的第三方模型 endpoint。维护默认使用聊天配置；配置了专用记忆槽时使用专用槽。没有本地模型兜底，也没有默认厂商。
- 外发内容：命中的用户轮次文本、scope、允许的 predicate、已有事实的 predicate/value（不含密钥）；摘要任务还包含需要压缩的轮次。附件原文、图片字节、聊天密钥不进入维护 payload。
- 预算：默认每日 **20 次调用 / 30,000 Token**；每次维护预留 **4,024 Token**（输入 3,000 + 输出 1,024）。默认上限下，满预留实际约 7 次调用就会触顶，而不是 20 次。用户可在 1..1000 次、1,000..1,000,000 Token 范围内调整。
- 未知：真实厂商的缓存折扣、失败重试的实际计费、以及维护任务在 100 轮下的真实日用量，本轮没有端到端账单；不能把 30,000 当实际花费。

## 2. 换会话、改口、停止回答、锁定、删除后分别发生什么？

- 换会话：历史保留；新会话按自己的 GLOBAL/NOTEBOOK scope 读取记忆。旧会话来源不会因为切换写进新 scope。
- 改口：同一 memoryId 生成新版本，旧版本 SUPERSEDED；默认不再注入旧值。人工保护冲突当前直接忽略自动候选，不进入 PENDING；这与 P9 用户裁决一致，旧 M05/F03 验收条目已按裁决覆写。
- 停止回答：保留已显示的部分正文，turn 进入 ABORTED；不会把未完成正文当成功学习，也不会自动重放。
- 锁定：记忆库锁定后不注入记忆，维护 job 等待解锁或按安全边界失败；不落明文密码。锁定前已经外发的请求不能被“撤回”。
- 删除：删除单条记忆清 item/evidence/proposal/suppression 链，原聊天消息仍保留；删除会话额外清证据和会话上下文；删除 notebook 清该 notebook 的 NOTEBOOK scope 记忆/job/提案/抑制并推进绑定会话 generation。删除不推进全局 history floor。

## 3. 默认不开向量/图服务，实际召回限制在哪里？

- 默认是 PREINJECT 的本地词法/结构选择，不调用远程 embedding，不建图服务，不把记忆明文写入检索表。
- 选择受 scope、ACTIVE/过期、suppression、token 预算和 **100ms** 记忆选择 deadline 限制；超时则本轮不注入，不阻塞聊天。
- 语义同义改写、跨语言召回没有保证；当前只证明了 90 例“提取”召回，不是检索 recall@5。没有证据支持“智能语义记忆”文案。

## 6. 历史分页、模型扫描、逻辑容量和物理 DB/WAL 大小分别是什么边界；是否还有隐藏的 500 条自动删除入口？

- 历史 UI 每页最多 **50** 条；前端驻留上限 **500** 条，超出只影响本地驻留，不触发数据库删除。
- 模型扫描按批读取，单批最多 **8 轮**，输入预算 **3,000 Token**，摘要模型可见 **600 Token**，摘要 payload 上限 **32KiB**；不是全库解密。
- 单次回复预留 **2MiB**，捕获原文上限 **1MiB**，`result_meta` 明文上限 **16KiB**，单列 `crypto_meta` 上限 **4KiB**。
- 逻辑容量按配置和预留计算；物理 `study.db` / WAL 文件本轮没有做真实上限压测，不能给出“物理文件不超过某值”的保证。
- 当前路径没有发现 500 条自动删除入口；500 是前端驻留上限，清理走显式清理接口。旧版本是否存在隐藏 prune 仍需在迁移/回退轨道复核。

## 7. 检查器显示的是哪个 attempt 的计划、哪些来源无法重看；续接摘要是否区分用户决定、助手建议和未验证完成？

- 检查器按 attempt 记录选中来源 ID/version、区域估算和 usage；metadata 不保存记忆/摘要正文副本。删除、改版、锁定后的旧来源显示占位，不能从旧 prompt/缓存恢复。
- 无法重看的来源包括：已删除/被替换的笔记版本、删除的记忆、锁定后未解锁的密文；旧 audit 的计数可能为 unknown，不冒充全库统计。
- 续接摘要区分用户自述完成（user_reported_done）、助手建议（未采纳不入 confirmedDecisions）和未验证完成；非法 verified/来源字段被拒绝。相关测试在 H14/H15 证据项；本轮 120 例只覆盖提取+回答，未覆盖摘要语义。
